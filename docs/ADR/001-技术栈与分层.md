# ADR-001 技术栈与分层

日期：2026-10-18　状态：已接受

## 决策
零依赖 Node 24 原生方案：原生 ESM、`node:test`、`node:http`、`node:sqlite`；前后端一体单进程，单体 Docker 部署。

## 分层与依赖方向（强制单向）
```
web(演出) → server(编排) → engine(纯内核) ← tools(编译/lint)
                ↓                ↑
              sqlite          universe/canon(数据)
games(剧本 DSL) --compile--> IR(JSON) --engine--> 演出状态
```
- engine/ 不做 I/O、不碰 DOM/DB；同 IR + 同选择序列 → 同结果（可回放、可 e2e）。
- 剧本不进引擎：DSL 编译为 IR，编译是纯函数（可快照测试）。
- 编译即加载：服务启动时从源码编译全部游戏，无 dist 中间态（避免陈旧构建）。

## 后果
- 新增 npm 依赖视为架构例外，须先立 ADR。
- 浏览器端零打包：web/ 与 assets/ 以原生 ESM 直出。
