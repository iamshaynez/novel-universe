# ch2-street
@bg night-street
@bgm rain

雨下得不轻不重，刚好把长街的霓虹泡成一滩一滩的影子。
「夜半茶寮」的灯牌在雨里明明灭灭，像某种迟疑的呼吸。

@show yan usual

屋檐下，一个穿黑风衣的女人转过头来。
沈砚：「你也收到信了？」
沈砚：「巧了。寄信人一共约了三个人——你是第二个。」
她推了推眼镜，目光越过你的肩膀，落在空无一人的街口。

* 跟沈砚进茶寮，等寄信人现身。 -> ch2-wait
* 绕去后巷——直觉说，寄信人在那里。 -> ch2-alley

# ch2-wait
@hide

茶寮里只剩一壶冷掉的茶，和两把背对背的椅子。
墙上的挂钟走到十点整，风铃响了。
小桃浑身湿透地站在门口，手里还攥着一封没有寄出的信。
小桃：「对不起……其实我谁都没有约。」
小桃：「我只是在等一个人，一个肯把这个故事听完的人。」
雨声忽然变得很远很远。
== ending END_WAIT 等来的人

# ch2-alley
后巷只有一盏坏了一半的路灯，光在积水里碎成鳞片。
黑暗深处，传来极轻、极轻的脚步声。

* 想起天台上她说的话，迎上去。 -> ch2-truth if fact.ev-rooftop-2019
* 犹豫了一瞬。就这一瞬，脚步声远了。 -> ch2-miss

# ch2-truth
@show momo cry

小桃站在灯影的边缘，雨水顺着发梢往下淌。
小桃：「十年前坠下去的人，是我姐姐。」
小桃：「那晚把她逼上天台的每一个人，我都记得——包括那天也在场的、『她』。」
她把一枚旧纽扣放进你的手心，转身走进雨里。
纽扣上，刻着茶寮的名字。
== ending END_TRUTH 雨停之前
