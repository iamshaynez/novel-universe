# ch2-ring
@bg factory-yard time=night
@date 二〇〇三年十一月十三日 · 深夜十一点

铺子里只点了一盏煤油炉，炉火在铁皮筒里发着暗红的光。
宋明坐在工作台前，眼睛死死盯着桌角那部红色的按键座机电话。
献血证上的年轻人面孔像一根烧红的铁钉，死死楔在他的眼眶里。
二十二岁，刘亮，川北南充人。
他用一双沾满机油的手，砸死了一个连声带都被烫坏、连呼救都喊不出来的后生。
就在这时，尖锐刺耳的电话铃声毫无征兆地炸响了。
「叮铃铃铃——」
铜铃在塑料外壳里剧烈震颤，回声撞击着满屋的生铁与扳手。
宋明整个人从长凳上弹了起来，后背撞翻了一架套筒扳手，铁件稀里哗啦砸在水泥地上。
铃声固执地响了七声，像催命的判官。
宋明深吸了一口气，抓起了冰冷的红色塑料听筒，贴在耳边。
他没有出声。

# ch2-pickup
@bg factory-yard time=night
@peak collapse

听筒那头是一阵冗长而空洞的静电杂音。
紧接着，两声沙哑沉浊的清嗓声传了出来：
「咳咳……」
这声音太熟悉了，熟悉得让宋明浑身的骨髓瞬间结冰。
那是韩荣抽了三十年烈性旱烟练出来的破锣嗓子。
韩荣：「宋师傅，深更半夜，还没睡啊？」
宋明死死攥住听筒，塑料外壳在他的指力下发出不堪重负的嘎吱声。
宋明：「……韩荣。」
电话那头传来一阵低沉刺耳的笑声，伴随着金火机砂轮在金属上刮擦的摩擦声。
韩荣：「我就晓得你认得出我的声线。昨晚在泵站，二十五公斤的铸铁滑轮，从六米高空直落，分毫不差砸在枕骨大孔上。宋师傅，到底是内燃机厂当过劳模的高级钳工，这门杀人的手艺，真是一点都没撂下。」
宋明咬着牙关，腮帮子的肌肉剧烈抽搐。
宋明：「死在泵站里的人是谁？」
韩荣的声音里带着一种猫捉老鼠的戏谑与残忍。
韩荣：「你翻过他兜里的献血证了？小刘，南充乡坝头来的娃儿，二十二岁。小时候嗓子被开水烫坏了，是个哑巴。在我的抵押车库里洗了两年车，老实得很，喊他往东不敢往西。昨晚我给了他两千块定金，说让他替我去收笔烂账，他就高高兴兴穿着我的羊皮大衣去送死了。宋师傅，你替我杀了他，我还真得谢谢你。」

# ch2-rage
@bg factory-yard time=night
@set phone_answered

宋明眼眶通红，低沉的咆哮从齿缝里挤了出来。
宋明：「韩荣！你是个畜生！他才二十二岁，跟你无冤无仇，你拿他的命当你脱壳的蝉衣？！」
韩荣在电话那头发出放肆的大笑，笑得剧烈咳嗽起来。
韩荣：「我畜生？宋师傅，动手的机关是谁安的？绳子是谁拉的？砸烂他脑袋的是你宋明的双手！退一万步讲，他替我死了，至少能拿七千块救他老娘的命；要不是你那一滑轮，他还能多活几十年呢！」

-> ch2-ultimatum

# ch2-ultimatum
@bg factory-yard time=night

韩荣敛住了笑声，语气陡然变得冰冷如刀。
韩荣：「行了，闲话少叙，谈买卖。融泰投资那一千两百万集资款，下周经侦就要查封，我必须走。现在警方、法医、甚至我老婆，都已经在公文上确认我韩荣被谋杀了。在法律上，我韩荣是个死人。可这个案子如果破不了，警方会一直追查我的资金流向，我的假死就不圆满。」
宋明冷冷开口。
宋明：「你想让我去自首？」
韩荣在电话里轻描淡写地敲了敲话筒。
韩荣：「两个选择。第一，去投案，就说因高利贷纠纷激情伤人，失手打死了『韩荣』。我老婆会出具刑事谅解书，我的律师给你做从轻辩护，判个七八年出来，我留五十万给你女儿治病。第二，明晚九点，火车北站，把那笔钱箱送到老地方。要是你想反悔，或者去警察局多嘴一句……全成都都知道你宋师傅杀了人。而我，早就死在解剖台上了。」
咔哒一声，电话挂断了。
盲音在寂静的夜里嘟嘟作响。
