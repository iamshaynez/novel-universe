# chA2
@bg heyin time=day
@date 十一月五日

十一月五日。
河音音像店在太升南路的口子上，卷帘门拉开一半。
磁带墙从地板顶到天花板。柜面玻璃下压着一张字条，圆珠笔字，一笔一画——
「本店无店歌。你听到喜欢的那首，就是。——禾」

秦姐：「贺青禾？顶班走了快两周了。」
她把数到一半的磁带放下。
秦姐：「落到河里头了嘛。十月二十七号早上，派出所来通知的。定性是意外——走夜路。」

「她家里人来过？」
秦姐：「她老汉儿来过一回，闹。喊她换号、换工作、离开这个城市。」
她的声音低下去。
秦姐：「她就说了一句——爸，借条上是我的名字。」
@set card.qh.note
秦姐：「那盘《告别》是她生前荐得最多的。她给人荐碟都写字条，字写得乖。」
秦姐：「她也不是啥时候都乖。客人照着流行榜买，她偏要劝人换一张。我说她得罪人，她说，卖错了更得罪人。」
秦姐：「她还问过我，铺面再小一点，租金会不会便宜。她想自己守一间。」
秦姐：「春天的时候她跟我提过一回，想换个呼机号。我说换啥子号嘛，熟客都记得。」
她把磁带码齐，没有再说下去。

青禾的合租房在厂后街，房东嬢嬢开了门。
屋里干净得过分。单放机在窗台上，磁带停在 A 面中间，电池早没电了。
单放机旁边，搁着她的呼机。汉显屏，边角磕掉了一块。
你按了一下。电还有。
屏幕亮起来，最近一条留言还存着：
「十点，老地方，河对岸等你。就这样。」
你站在窗前，把这一行字看完。
台里的底单，你收着；派出所的抄录，在卷宗里；这里还有一份。
发出去的话，有三处存着。你抽得走一处。
@set card.qh.pager

床底下一双雨靴，鞋尖冲外，摆得很正。
@set card.qh.rainboots
你问了一句。嬢嬢想了想——落水那晚，她穿的是布鞋。
「要去对岸工地的话，不穿雨靴，脚咋遭得住嘛。她那么仔细的一个女娃儿……」
嬢嬢又说，那晚十点半过，她还在屋头打了个电话。「我在走廊听到的，没听清说啥子，就听到她声音不对。」
你记下了这个时间。十点半过。

# chA2-tai
@bg chuantai time=day

回程路过传呼台，你进去核对材料。
杜鹃看见你，愣了一下。
杜鹃：「妹儿——」
她把后半句咽了回去，重新起头。
「老师。这回又换衣裳了喃？你们协查，一天一个样。」
「便衣嘛。」
她「哦」了一声。不再看你的眼睛。
@peak inner
她认出来了。那声「妹儿」不是口误。
她不喊破。这层纸，你们一人捂着半边。
头一回那件皮夹克，也是你。你换衣裳，只是给人留一个连不成一趟的余地。
那件皮夹克此刻叠在更衣柜最底层，证件缝在内袋——贴身的那一层。
证件是假的，姓名那一栏你每次都用拇指压着。
其实不压也不要紧。那上面的名字，本来就不是你。

# chA2a

「贺国栋的账，利滚利早过三万了。喊他女儿那个号——莫得了嘛，人都莫得了。」
「这单账，归哪一桌管？」你多问了一句。
他看了你一眼，没答。

# chA2b
老彭翻着卷宗接待你。
老彭：「定性意外，家属无异议，结都结了的。」
你翻到遗物登记那几页。汉显呼机一只，留言存稿四条，抄录在附页。
你逐条看完。最后一条：「十点，老地方，河对岸等你。就这样。」
临走他补了一句。
老彭：「前几天是不是也有位市局的老师来调过材料？搞忘登记名字了。」
「哪个？」
老彭想了想。「四十来岁，一个男老师，客气得很。」
你没有再问。除了你，还有一个人在查。这件事你先记下。

# chA2d
@bg funanhe-bank time=night
@card funanhe

入夜，你走到府南河边。
这条河小时候来过——那时河这边还是烂棚棚，水是黑的，风一吹整条街捂鼻子。
如今水泥堤岸砌得笔直，柳树一排，散步的人一拨接一拨。
只有对岸——对岸修路，围挡立成一排矮墙，没有一盏灯。
像这条街特意留给黑夜的一块自留地。

你从桥头往对岸走了一趟。
围挡把人行道截断了，要过去，只能贴着堤岸的水泥沿走。
沿只有一脚宽。黑，没有灯，下面是水。
你穿平底鞋，慢慢走，走了十一分钟。跑的话，六分钟。
你停下来，把这两个数字记在本子上。
她那晚穿的是布鞋。如果她还赶时间，她会跑。
桥头有个卖糖油果子的推车，收摊前最后三串没卖掉。
你没拿。你在桥头站了很久，久到车轴的吱呀声走远到听不见。
腰间的汉显机又震了一下。这一次你没有看，让它震完。

# chR3
@bg chuantai time=night
@date 十月二十六日

十月二十六日，霜降后两天。
如果记忆是一盘磁带，这一晚的 A 面会在往后每一夜被剪断又接上。
这一章，是那一晚。

九点四十，一个女声打进来，背景里有娃娃在哭。
呼的还是那个号。她的话不长：他躲出去快一个月了，屋头的钱他带走一半，喊他回来，当面把话说清楚。
九月二十八那晚，「明晚之前」四个字，是你添的。他是在那之后走的。
这一条你原样发了。铅笔拿起来，又放下了。

晚上十点。333-1188。

「麻烦你，呼六六八八转七。留言——别躲了。你爸签了字的。就这样。」
「别躲了」三个字，你打得很慢。台里没有一条规矩教你该怎么拦。挂机前，轻咳一声。

@transcribe t7 caller=陈先生 target=别躲了。你爸签了字的。就这样。

十点二十。河音的小柯，声音闷闷的。

「呼六六八八转七——碟给你留到最后一张了。就这。」
你敲「最后一张」的时候，只当又是一次留碟。

@transcribe t8 caller=小柯 target=碟给你留到最后一张了。就这。

十点三十五分。
一个女声打进来，很轻。
「姐，麻烦你——」
她停了。电流声里，你听见她把什么咽了回去。
你的手指已经搭在键上，等她的号码和留言。
「算了。不呼了。」
你没有问。台里的规矩，只递话，不问话。
挂断之前，她又补了一句，还是客客气气的调子：
「你们夜班，辛苦。」
滴。忙音。
这一通没有留言，不入账，底单上不会有她。
你本可以说一句「妹儿，你慢慢讲」。接线员也是人，这一句不违规。
你等她先挂。她挂了。你等下一条呼入。

十点四十七分。901-7544。
电流声深不见底。
那个又稳又冷的声音：
「麻烦你，呼六六八八转七。留言——老地方，河对岸，等你到十二点。来不来，你自己定。就这样。」

你把这句话照原样打了出来。
老地方，河对岸，等你到十二点。来不来，你自己定。
「老地方」三个字，你按重了。
你的手指停在键面上。
你想起十点三十五那个女声。想起她咽回去的那半句。
你也想起姓王的说的：紧一紧。今晚这单，他白天递过话——要她出来。
你把这行字删了。
重打——
十点，老地方，河对岸等你。就这样。
「等你到十二点」，你删了。「来不来，你自己定」，你删了。「十点」，是你添的。
发送的时候，已经十点四十七。
她收到的那一秒，就已经迟到了。
@peak dead 22:47
@transcribe t9 caller=刘先生 target=十点，老地方，河对岸等你。就这样。

@fact ev-g01-message

滴、滴。两条短音，落进城东某处一只黑色的呼机里。
你跟自己说，只是紧一紧。话还是他的话，号还是他的号。
你只是把「你自己定」，当成了可以削掉的骨头。

清晨八点，杜鹃来接班，脸色不对。楼道里乱。
「河里捞起来了个人。」「就是六六八八转七那个妹妹嘛，河音的。」
「派出所的来问过话了。」

@fact ev-g01-heqinghe

定性很快下来——意外，走夜路，失足。家属没有异议。
台里照常上班。值班本上那栏红圈，被老金用涂改液涂掉了。
你在洗手间站了很久。
你想的不是「别躲了」，也不是「河对岸」。
你想的是那半句「来不来，你自己定」。
它如果还在，她可以不来的。
你把水龙头开到最大。水声盖过一切，那句话没有被冲走。
