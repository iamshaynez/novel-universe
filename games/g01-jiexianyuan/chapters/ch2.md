# chA1
@bg chuantai time=day
@date 十一月三日

十一月三日，下午。
「锦声传呼台」四个字在白天的街面上显得旧。
推门进去，楼道里堆着装呼机包装盒的纸箱，一直堆到二楼。
白班六个座席只有三个有人，耳机线在隔板间缠成一团。
一楼半的转弯处，你问一个抱纸箱的师傅——档案室在哪边。
「底楼最里头嘛。门牌掉了的那间。」
你没有问路以外的任何话。这栋楼你不需要介绍。
你今天是市局来协查的。

# chA1-archive
门牌果然只剩两个锈钉子。灯的拉绳断了一截。
你摸黑把卷宗柜最下层抽出来，就着窗户的光，用笔抄。
白班的座席空着三张。你站在隔板外，没有坐下去。
抄到第三页，有人推门。

老金：「哎哎哎，同志！你是——」
你把证件举到他眼前，拇指压着姓名那一栏。
「市局，协查。贺青禾的事。」

他看了一眼证件。只一眼，就挪开了眼睛。
老金：「哦哦哦，你说协查，就协查嘛。同志，材料……材料都归档了嘛，你抄这些——」
他认得你。认得的人，不需要看第二眼。
你举证件，赌的不是他认不出——是他不敢认。
认了，就要问「苏晚，你搞啥子」。问了，就要登记。这一行，他这辈子都不会签。
「归档在哪里？」
老金：「就……就在这间嘛。」
他的手在柜子上虚虚地拍了两下。
他摸出烟来敬你，你摆手。他自己点，手抖，火柴划了三根。
不瞒你说，十月二十六号之后，台里出过一回失窃。
底单少了一叠。恰恰是二十六号前后的。没报案——小台，怕麻烦。
你说邪不邪门。

# chA1a
夜班表上，十月二十六日晚十点到次日八点，值班人一栏写着两个字——苏晚。
你把这两个字抄下来。笔尖在「晚」字最后一捺上停了停。
这一捺你写过几千遍。签到，签退，电大的作业本。
你翻过去，抄下一行。没问任何人她是谁。

# chA1d
傍晚你离开传呼台。
走出两条街，腰间的汉显机震了一下——屏幕上跳出一串数字，尾号是个「王」字。
你看了一眼，按掉，把它翻过去扣在腰上。
夜色落下来，太升南路的灯箱一块块亮起，红一块绿一块。
你混进人堆里，像一滴水回到水里。

# chR2
@bg chuantai time=night
@date 九月二十八日

九月二十八日，秋分后五天。距离那件事，还有二十八天。
晚上十点半，那个又稳又冷的声音回来了——但报的回电号是新的。

「麻烦你，呼六六八八转七。留言——东西准备好了，周六，老地方。就这样。」
发送。挂机前，那头照例轻轻咳了一声。

@transcribe t4 caller=刘先生 target=东西准备好了，周六，老地方。就这样。

你皱了皱眉。
十四天前那位「陈先生」也是这个调子——句尾「就这样」，挂前一声咳，客气得发冷。
可回电号对不上。一个是 333-1188，这回是 901-7544。
你在底单两行各点了一个铅笔点，把两个号码并排看了一会儿。
也许是两父子。也许是两兄弟。成都话讲，屋头出事，七大姑八大姨都来了。

十一点，一个粗嗓门打进来，背景全是游戏厅的电子音。
「我是康乐街机城的罗老三！呼我那娃儿伙计——机器修好了，喊人来搬！」
@card pankou
他忽然压低声音。
「顺便说一嘴，最近风声紧，盘口都改到茶馆后头去了。喊他们脑壳放活点。」

@transcribe t5 caller=罗老三 target=机器修好了，喊人来搬。

你打完这条，摇摇头笑了。正经话和江湖话，都得从同一张底单上过。

零点过一刻，张嬢嬢的儿子终于回了。
「呼我妈——晓得了，莫念。加衣服。」
五个字，加三个字。你几乎能看见那头的年轻人一边穿夹克一边打的电话。

@transcribe t6 caller=张嬢嬢之子 target=晓得了，莫念。加衣服。

后半夜来了一笔「私活」。
不是呼六六八八转七，是另一个号。一个欠赌账的机主，呼入的人把话讲得软：「钱的事，这两天，你看着安排。」
你照规矩可以原样发。
你把它删紧了——「钱的事，明晚之前。就这样。」
「你看着安排」五个字，你删了。「明晚之前」，你添的。
发送。底单上只占一行，和别的留言没有两样。
姓王的说过，紧一紧。这就是紧一紧。不犯法，不多一个字，不少一个号。
你盯着那一行看了一会儿，在边上点了一个极小的铅笔点。
这一次的点，不是因为声音里有多余的东西。
是因为你自己添了东西。

清晨六点，离交班还有两个小时。杜鹃提前到了，拉你上天台吃茶叶蛋。
天上没有月亮。

@set card.dj.percent
杜鹃：「妹儿，我们这行，耳朵头过的话，百分之九十九莫得意义。你莫想多了。」
「最近呼六六八八转七的，好像不止一路人。」
杜鹃：「贺青禾嘛。家里出了事都这样。她老汉儿东郊厂下来的，多好的钳工，下了岗就……」
她做了个数钱又飞了的手势。
杜鹃：「娃儿造孽。」
杜鹃：「对了，你学费缴清了？上回还听你说差一截。」
「缴清了。」
「那就好。好好读，读出来就不用熬夜了。」
百分之九十九。你把茶叶蛋的壳捏紧了一点。
剩下那百分之一呢。
