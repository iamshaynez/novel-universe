# g02-halftime
@bg houzimen-billiards time=night
@date 中场休息

中场休息，前堂的人终于肯坐下一点。
平时这十几分钟有人续茶、有人上厕所、有人争于根伟那个球到底该谁包抄。今天没人起身，大家被分成几小堆，轮流回答何峥的问题。
陈拾坐在球台边，绿呢顶灯照着他。他看见自己的打卡纸、钥匙和现金箱被分别装开，像三样已经商量好的东西。
何峥：「唐国梁，你再说一遍。你跟冯世昌进器材室以后，谈了什么？」
唐国梁：「盘账。明天要对账，他把白天的数过了一遍。我先出来看堂子，他在里面写。」
何峥：「有没有争？」
唐国梁：「账上有出入，做生意的，争两句难免。没到动手的程度。」
何峥：「多少出入？」
唐国梁停了一下。
唐国梁：「旧账，有两万多。」
何峥：「具体点。」
唐国梁：「二万八千六。」
陈拾抬起头。这个数字他见过，在冯世昌那张便签的背面。

# g02-shift-note
@date 中场休息 · 问询继续
@bg houzimen-billiards time=night

班次页被翻出来。冯世昌的字，陈拾认得。
纸上写着「小陈，八点」。旁边还有一行更小的字，是「陈拾请早退」。
陈拾：「我没请过。」
何峥：「老板自己愿意让你提前走？」
陈拾：「他说让我看比赛。我以为就是这个。」
何峥：「你没求过，他为什么写你请早退？」
陈拾答不上来。
唐国梁：「年轻人想看球，老板照顾一下也正常。现在问这个，跟箱子有啥关系？」
何峥：「有没有关系，我们自己判断。」
账簿里夹着一张便签。不是完整计划，只有几行时间和物件。
「八点，陈下班。」
「盘账，器材室。」
「终场，报失。」
最下面是「钥匙、柜、电视」。
何峥把便签看完，再翻到背面。背面有一个数「28600」，后面两个字是「唐经手」。
何峥：「如果冯世昌今天没死，终场以后会发生啥？」
唐国梁没有回答。
何峥把便签放到现金箱旁边。
何峥：「终场以后，现金箱报失。钥匙在你的柜里，你提前下班，没人看着你，旧账也可以顺着说是你拿的。这个局不是给你准备的，是给一个贼准备的。」
陈拾：「你是说，冯老板本来要冤枉我偷钱？」
何峥：「至少这套准备在他死前就有了。」
陈拾心里先是松了一下。
如果他早就准备栽赃，那就不是有人杀完人以后突然想出来的。
可何峥下一句话，把那一点松又压了回去。
何峥：「你也有可能早知道。你们一起做假失窃，分钱没谈拢，你把他杀了，再装成自己也是被害的。」
陈拾：「我没有！」
何峥：「那就把你晓得的全部说出来。特别是这张纸。」

# g02-copy-choice

陈拾认得便签中间那两行字。不是冯世昌的，是他的。
几天前，冯世昌让他照着一张草稿抄过。冯世昌说自己眼睛花，让他写大点。他问这是啥，冯世昌只说盘账用。
当时他抄完就忘了。现在那两行字到了警察手里，变成了他是不是同谋的证据。

# g02-old-accounts
@date 中场休息将尽
@bg houzimen-billiards time=night
@fact ev-g02-fake-theft

旧账的来路并不清楚。冯世昌管大钱，唐国梁管每天交接，谁都有机会把一笔数挪到另一本账上。
唐国梁承认二万八千六不是一天短出来的，却说具体怎么短的要等对账。
何峥：「『唐经手』是啥意思？」
唐国梁：「我经手过，不代表就是我拿了。冯老板也经手。」
这句话不能替他开脱，也没有把责任全推给他。
陈拾听着，第一次觉得这家店的账跟球房不是同一个地方。球房里每根杆都有位置，账上的钱却可以从一个名字走到另一个名字。
何峥：「如果是冯世昌准备假失窃，唐国梁晓得多少，陈拾又晓得多少，都要分开查。不要拿一张纸就把三个人写成一伙。」
陈拾听见这句，抬头看了何峥一眼。
至少还有人在分「谁写了什么」。

# g02-zhaobo-1995
@date 下半时开球前
@bg houzimen-billiards time=night

下半时要开始了。何峥让前堂继续开着电视，但不许围到后头来。
赵伯不肯回座位，非要把一句话说完。
赵伯：「你们年轻人看球，觉得一比零就够了。九五年那才叫人坐不住。最后一轮，成都体育中心，全兴对八一，翟飚，脑壳顶进去的。那一个球才保级。」
温荟：「不是青岛吗？」
赵伯：「青岛是前一轮。最后一轮是八一，这个我记得，不会错。」
骆师傅：「马明宇那年不在全兴嘛，你不要又把马儿安进去。」
赵伯：「我啥时候安了？翟飚，翟飚！」
何峥：「说回今晚。你记不记得前几天谁谈过报失、遭贼？」
赵伯这才停下来想。
赵伯：「店里账不对的时候，闲话哪个没说过？对不上就说遭贼，年轻人说不清——这话我听倒过。当时只当是开玩笑。」
何峥：「哪个说的？」
赵伯皱着眉。电视里下半时快开了，他的脸还向着球场，努力把那天的声音从球赛里分出来。
赵伯：「现在一下子问，我不敢乱安。让我想哈。」
陈拾站在旁边，心里那句「年轻人说不清」，却怎么都压不下去。
