// 第一章 · 上岗（序章 + R1 白露）

# ch0-open
@bg chuantai time=night

一九九九年九月十日，夜。
太升南路把一整天的喧闹收进卷帘门，只剩通讯一条街的灯箱还醒着，红一块绿一块。
「锦声传呼台」的玻璃门后，白班正要交班。
杜鹃摘下耳机，脖子转了两圈，响得像拧发条。

杜鹃：「交接了哈。今晚呼量不大。张嬢嬢肯定要呼她儿子，你莫拦；修机的向师傅那台座机又串音，喊他们明天来看。」
她把值班本推过来。
值班本摊开的一页上，有一栏被红笔圈过——「6688-7 频呼，注意文明用语」。

* 先去走廊尽头泡一杯三花茶。 -> ch0-tea
* 先做开台检查，六个座席挨个试一遍。 -> ch0-check

# ch0-tea
茶在走廊尽头泡上，氤氲的热气里，耳机戴上的一瞬，世界只剩电流的沙沙声。

# ch0-check
墨绿的台内机按键按下去有半拍延迟——老机器了，但它记得每一个号码。
-> chR1

# chR1
耳机戴上的一瞬，世界只剩电流的沙沙声，像隔着一层薄雨。
二十四张座席，夜班只亮六张，荧光把每张脸都照成同一种青白色。
楼下卷帘门哗啦一声又一声地远了。
十点零七分，第一声呼号很轻，很客气——那是常态，一座城市在往你的手指里排队。
-> chR1-bailu

# chR1-bailu
九月十四日，白露过后第七天。
秋意是从耳机里先来的——那晚的留言，一半在说冷。
你上夜班三个多月了。白天的你读电大，夜里的你管另一路数字。
打字跟人声走——人急，键要快；人慢，键要等；人哭，你要打的字就得替他把哭咽回去。

「呼我儿——降温了哈，被子换成厚的，莫要嘴硬。你老汉儿风湿又犯了，念你。」
中气十足的女声，字与字之间不留缝。张嬢嬢。
你照打。「念你」两个字敲进去的时候，指尖顿了半拍。这两个字最贵，也最值。

@transcribe t1 caller=张嬢嬢 target=降温了，被子换成厚的。念你。

十一点过，一个年轻人打进来，背景音是音像店打烊的卷帘门。
「我是河音的小柯，呼六六八八转七。新到了一批打口碟，给你留了最后两张，就来。」
六六八八转七。红笔圈过的号码。台里人都认得，机主是河音音像店的妹妹，贺青禾。

@transcribe t2 caller=小柯 target=打口碟到了，给你留了最后两张。

十一点四十分。
电流声深了一层，像打电话的人换了个更暗的角落。
「麻烦你，呼六六八八转七。留言——钱的事，再宽限几天。就这样。」
中年男人，声音很稳，稳得发冷。
你的手指停在「宽限」两个字上。这个话太重了，重得不像三毛钱一条的留言。
但你还是打了。台里的规矩——只递话，不问话。
挂机之前，那头轻轻咳了一声。

@transcribe t3 caller=陈先生 target=钱的事，再宽限几天。就这样。

你盯着底单看了两秒。这个人客气得——怎么说呢，客气得像把刀包在了帕子里。
你在「宽限」旁边用铅笔点了一个极小的点。
这是你的习惯——声音里有多余的东西，就点一个点。
那一晚你转了十四条留言。成都人把话磨成骨头，因为传呼按字收费。
夜班的第一夜，就这样开始了。
