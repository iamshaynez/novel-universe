# 五章结构与行动坡度

## 总体拓扑与设计原则

- **单夜球赛时钟（HUD `@date` 驱动）**：五章严格对应 2001-10-07 中阿之战的五个时段（赛前至第36分钟 → 上半时尾声 → 中场休息 → 下半时 → 终场哨前与散场）。
- **让读者先赢一局小的，再输掉一局大的，最后亲手翻盘**：
  - ch2 末读者凭“开球前柜门顶住”看穿现金箱早就在柜里（小胜）；
  - ch3 翻出死者生前假失窃与陈拾亲笔便签，叠加“进球时间”公共钟与骆师傅罚单，陈拾陷入“同谋内讧杀人”的灭顶绝境（大败）；
  - ch4 陈拾背对屏幕，通过「对表」用汉显机与 19:58 座机电话拆穿第36分钟公共钟（主诡计大翻盘）；
  - ch5 拆穿“谁是白球（计划作者）”，并在终场哨响、警力抽调去天府广场的死线前，完成“可信度＝说全”的终极抉择。

## ch1《开球》（18:30 至上半时第36分钟）

- **场景与节拍**：
  1. `g02-kickoff`（18:30）：后子门台球厅赛前预热。电视被唐国梁从下午起挪到堂心；赵伯念叨全兴与马儿；温荟坐在吧台边频频看座机和门口（等同学电话）；骆师傅把出租车停在街边。
  2. `g02-pager-habit`（18:47）：冯世昌腰间汉显机响，两分钟内从器材室出来到吧台用座机回电（立下“汉显机+座机、三分钟必回”的私人钟习惯）。冯世昌顺口让陈拾今晚八点提前打卡下班看球。唐国梁叫住冯世昌低语两句，冯世昌在班次本添字——**陈拾没听见内容，只当老板和经理照顾自己**。
  3. **选择点 1（观察分支）**：
     - `* 先把里头两张球台收干净，省得明天挨说。` → `g02-finish-tables`（置 `@set finished_tables`）：唐国梁过来帮陈拾压平球杆，顺手教他打一杆组合球（**“打前头那颗，让它替你送。白球停住就对了，白球最忌讳跟着进去”**）。
     - `* 先凑到电视机前头，听赵伯摆首发名单。` → `g02-listen-zhao`（置 `@set listened_zhao`）：赵伯讲马儿、祁宏停赛与于根伟首发，唐国梁在旁边擦杆，随口拿球台上的组合球打比方（同样埋下“白球最忌讳跟着进去”的主干台词，确保主干保底）。
  4. `g02-locker`（19:05）：陈拾去窄廊塞围裙，柜门被里面硬物顶住，他用膝盖顶上锁好。
  5. `g02-pregame`（19:30 开球）：中国队白衣开球。19:45 冯世昌与唐国梁进器材室“盘账”，吧台交陈拾看管。
  6. `g02-call-1958`（19:58，「一拦」）：骆师傅刚换完零钱出门挪车。吧台座机骤响，温荟第一个站起来（以为是同学，失望坐下）。陈拾接起，是冯家问“呼了他两遍咋不回电话”。陈拾正要去器材室喊人，唐国梁从窄廊走出来按住话筒拦下他：“莫去，他在里头对着旧账发火，等哈我跟他说。”
  7. `g02-goal`（20:06 上半时第36分钟，「一送」与峰值）：于根伟破门！**唐国梁在堂心一把抱起赵伯转了半圈**，全场沸腾。欢呼稍落，唐国梁拍陈拾后背：“去，拿盒新皮头，顺便给冯老板报个喜，把他屋头来电话的事也说了。”陈拾推开器材室门，手电光照见冯世昌后脑的血（`@peak dead`）。

## ch2《一比零》（20:20 至上半时结束）

- **场景与节拍**：
  1. `g02-police`（20:22）：何峥带民警到场封锁前后门。对讲机里已在通报终场后天府广场方向的执勤预案（埋下终场死线）。唐国梁沉稳配合，随口说出**“进球那阵堂子里吵成那样，里头就是喊破喉咙外头也听不见”**——把所有人的记忆锚死在 20:06 公共钟上。
  2. `g02-keys`（20:35）：后门内闩锁死，打卡纸显示陈拾八点整下班，进球时无人能证明陈拾在吧台。唐国梁“好心”替陈拾担保老实，却顺口道出“兼职柜里挂着器材室备用钥匙”。
  3. **选择点 2（诚信档案一：钥匙交接）**：
     - `* 把钥匙交接的规矩和今晚谁进出过窄廊全说清楚。` → `g02-keys-full`（`@set told_keys`）
     - `* 先只认柜子是自己的，钥匙的事推说还没交接。` → `g02-keys-hide`（`@set hid_keys`，唐国梁立刻递上交接本，陈拾第一次体会到“少说一句反而让纸面更完整”）。
  4. `g02-pockets`（20:45，口袋里的纸与遗物清点）：何峥清点众人随身时段凭证与死者遗物。骆师傅掏出 20:04 街边违章停车罚单；温荟捏着没用上的电影票根；唐国梁口袋里有一张次日北站预售车票（轻描淡写说是屋头私事，混在众人纸片中）；冯世昌腰间取下那台摩托罗拉汉显机（屏幕亮着未读提示，暂未展开时间戳）与账本。
  5. `g02-ledger-search`（20:52）：吧台 4,760 元营业款现金箱失踪。何峥逐一开柜，陈拾柜门弹开，围裙上赫然放着现金箱（`@peak desk`）。陈拾想起开球前顶住柜门的那一下，却明白此刻空口无凭。

## ch3《中场》（中场休息，十五分钟绝境）

- **场景与节拍**：
  1. `g02-halftime`：中场休息，堂内气氛凝滞。何峥追问器材室盘账内容，唐国梁点出“账面有出入”。
  2. `g02-shift-note`：班次表“陈拾请早退”与夹在账本里的便签翻出。便签正面写着“八点，陈下班 / 盘账，器材室 / 钥匙、柜 / 终场，报失”，背面写着“28600 唐经手”。何峥指出冯世昌生前就在准备假失窃，但紧接着反问：**既然是假失窃，为什么中间两行“钥匙、柜”是陈拾的笔迹？**
  3. **选择点 3（诚信档案二：便签笔迹）**：
     - `* 承认中间两行是几天前帮冯老板抄的，把经过说出来。` → `g02-copy-full`（`@set told_copy`）
     - `* 咬牙否认，说没见过这张纸，免得被当成同谋。` → `g02-copy-hide`（`@set hid_copy`）
  4. `g02-old-accounts`（`@fact ev-g02-fake-theft`）：何峥拼出“同谋分赃不均杀人”的嫌疑链——在 20:06 进球这口公共钟下，唐国梁正抱着赵伯欢呼（全场作证），骆师傅在门外贴罚单（20:04 罚单作证），全店只剩陈拾有钥匙、有赃箱、有亲笔便签、且在进球时无人注意。
  5. `g02-zhaobo-1995`：下半时即将开球。赵伯提起 1995 年成都体育中心全兴 1:0 八一、翟飚头球保级（陈拾想起自己十三岁坐在父亲肩头看球，大家只记得顶进去的那一下，没人记得前头八十多分钟球是怎么传的），并漏出半句残片：“对不上就说遭贼，年轻人说不清——这话我前两天听哪个说过……”
  6. **选择点 4（中场绝境：留下来对表 vs 翻窗逃跑）**：
     - `* 不跑。把脸从电视机那边转回来，留在堂子里把时间一分钟一分钟算清楚。` → `g02-stay`（进入 ch4）
     - `* 趁下半场开球前堂骚动、后廊没人盯死，从窄廊气窗翻进后子门夜巷。` → `E_RUN`（直接进入逃避结局《人潮》）

## ch4《下半场》（主诡计章：背对屏幕与「两只钟」对表）

- **场景与节拍**：
  1. `g02-second-half`：下半时开球，阿曼射门擦柱而出，全场倒吸凉气。陈拾第一次**彻底背对电视屏幕**（“我看不懂球了，我只看这间屋子”）。
  2. **选择点 5（拆第一重锁：柜门与现金箱时间）**：
     - `* 请何警官带自己回窄廊，把空柜门重新开关一次。` → `g02-reopen-locker`（`@set reopen_locker`）
     - `* 直接说出七点零五分开球前柜门就被硬物顶住、赵伯在外头催看首发。` → `g02-locker-time`
     - （合流置 `@set told_locker`：赵伯证实开球前听见陈拾用膝盖顶柜门。现金箱入柜时间前推至开球前，拆掉“杀人后栽赃”）。
  3. `g02-pager-inspect`（触发私人钟）：何峥指出，就算箱子开球前就在，仍不能排除陈拾在 20:06 进球时进器材室杀人。陈拾盯着证物袋里冯世昌的遗物，请求核对冯老板的随身汉显机。
     - 屏幕点亮：两条未读汉字传呼——**`[01] 19:52 速回屋头电话`**、**`[02] 19:57 屋头等，见字速回`**。
  4. **选择点 6（「对表」推理第一问：私人钟的异常）**：
     何峥问：“两条未读传呼，能说明什么？”
     - `* 冯老板舍不得手机费，一贯汉显机一响三分钟内就到吧台回座机——他七点五十二分就已经回不了电话了。` → `g02-clock-step2`
     - `* 说明冯老板当时正在跟人吵架，顾不上看腰上的呼机。` → `g02-clock-hint1`（陈拾自己想起 18:50 冯老板连盘账都出来回电话的铁律，重回正轨进入 `g02-clock-step2`）
  5. **选择点 7（「对表」推理决胜问：冯世昌死在什么时候？）**：
     将 `19:52/19:57 未读传呼`、`19:58 吧台座机来电与唐经理出窄廊拦人`、`20:06 于根伟进球唐经理抱赵伯`、`20:07 唐经理差陈拾进屋报喜` 四件事排在同一根时间轴上。何峥盯着陈拾：“那你告诉我，冯世昌到底死在什么时候？”
     - `* 死在七点五十前后——进球前十五分钟。唐经理七点五十八拦住我，是为了不让我提前发现尸体！` → `g02-two-clocks-solved`（`@set time_solved`，主诡计大翻转）
     - `* 还是死在八点零六分于根伟进球那一下——只有那时候欢呼声最大，能盖住动静。` → `g02-clock-retry`（何峥冷声提醒：“进球那一下唐国梁正抱着赵伯转圈，满堂子人看见。你再想最后一次：呼机为什么七点五十二就没按过？”）
       - 在 `g02-clock-retry` 二次选择：
         - `* 我算反了！他死在进球前，七点五十二以前就已经不能动了！` → `g02-two-clocks-solved`（`@set time_solved`）
         - `* 我还是觉得只有进球那阵才下得去手……别的我算不清了。` → `E_WRONG`（进入歧途结局《重播》）
  6. `g02-two-clocks-solved`（`@peak split`，两只钟交叉换位）：
     - 陈拾当场叫出温荟！温荟证实：19:58 吧台电话响时她以为是同学找她，第一时间站起身，亲眼看见陈拾接电话、唐国梁从窄廊走出来拦住陈拾说“莫去”，而那时离于根伟进球还有足足七八分钟！
     - 两只钟彻底翻转：19:50–19:58 死亡窗口内，陈拾守在吧台，骆师傅在换零钱，**唯独唐国梁在器材室里**；而 20:07 亲手把陈拾推进器材室当发现者的，正是唐国梁自己！

## ch5《终场》（终场哨前对峙与可信度终局）

- **场景与节拍**：
  1. `g02-final`（温荟与“求早退”谎言）：唐国梁被推上台面，却依旧冷静。陈拾追问温荟赛前唐经理跟冯老板在吧台说了什么；温荟证实原话是**“小陈来求过，想早点走”**。第四层真相揭开第一角：把陈拾推上替罪羊位置的，从一开始就是唐国梁。
  2. `g02-zhaobo-truth`（赵伯与“遭贼”主意）：陈拾转身追问赵伯中场没想起来的那句话。因为 19:58 的假面已被撕开，赵伯猛然省悟，拍着大腿指认：**“对不上就说遭贼，年轻人说不清——这话就是唐国梁前两天在吧台跟冯老板说的！”**
  3. `g02-plan-author`（`@fact ev-g02-fengshichang`，白球落袋）：何峥翻出唐国梁外套里的北站预售票与“28600 唐经手”账页。陈拾看着满桌冯世昌亲笔写的纸，说出那句回敬：**“唐经理，你刚才教我打球的时候说过——打前头那颗，让它替你送，白球最忌讳跟着进去。冯老板是那颗红球，你是那颗白球。可七点五十二分，白球进袋了。”**（`@peak inner`）
  4. `g02-credibility-clash`（唐国梁的反扑与终场死线）：
     - 何峥的对讲机响起急促调度：比赛进入伤停补时，终场哨一响，天府广场上万球迷聚集，辖区警力必须立刻抽调支援。
     - 唐国梁抓住最后几分钟发起反击：**“警官，温荟只听见电话响，没听见电话里说啥；说我拦他、说我叫他进去报喜，全是他陈拾一张嘴！可钥匙在他柜里，箱子在他柜里，那张假失窃便签上‘钥匙、柜’六个字是他陈拾亲手写的！一个连自己笔迹都不敢认（或掺合过假失窃）的嫌疑人，他的话能当铁证扣我？”**
  5. **按诚信档案分流（`if hid_copy` vs `if told_copy`）**：
     - 路线 A（`if hid_copy`，ch3 曾否认抄写便签）→ `g02-dilemma-hid`：
       何峥把便签拍在桌上逼问陈拾：“你中场跟我说没见过这张纸。你要我信你说的七点五十八，现在就得把这张纸的底交出来。你一旦认了，刚才就是对警察做伪证，假失窃你也脱不了干系！”
     - 路线 B（`if told_copy`，ch3 已承认抄写便签）→ `g02-dilemma-told`：
       何峥要求陈拾交出家中机电课本里的便签原稿并签署正式指控笔录（这意味着陈拾帮抄假失窃便签的事将正式入卷通报学校与家里）。趁何峥接听对讲机调度的一瞬，唐国梁压低声音递来最后一桩交易：**“小陈，我可以说开球前亲眼看见冯老板往你柜里塞箱子。你把假失窃和命案全摘干净，只要你现在改口，说七点五十八记不准了。”**
  6. **选择点 8（终局抉择：说全 vs 散场）**：
     - `* 把便签原稿、帮抄经过和自己今晚每一句私心都说全，一个字不省。` → `E_FULL`
     - `* 到此为止。只保住“箱子开球前就在柜里”，便签原稿与七点五十八的咬死指控不再往下递。` → `E_LEAVE`

## 四个结局的回响设计

| 结局 ID | 标题 | 触发路径 | 核心戏剧画面 |
|---|---|---|---|
| `E_FULL` | **说全** | ch4 对表正确 + ch5 选择说全 | 终场哨响，中国队 1:0 提前两轮出线。唐国梁交出外套被铐走，陈拾也须随警车去取机电课本里的原稿做笔录。门外全城人潮涌向天府广场，只有陈拾逆着人流走下台阶；赵伯追出来把凉透的三花茶塞进他手里：“比赛还有重播，你先把你的事情说完。” |
| `E_LEAVE` | **散场** | ch4 对表正确 + ch5 选择收手 | 终场哨响，对讲机催促警力立刻支援天府广场。因缺少陈拾交出原稿与咬死的最后证言链，何峥只能先把陈拾排除直接行凶，却无法当场扣押唐国梁。唐国梁搭着外套走下台阶，混入满街挥舞国旗与号外的人潮。陈拾站在门口，手里像一辈子攥着那张没交出去的纸。 |
| `E_WRONG` | **重播** | ch4 对表两次锁定“进球时” | 无法撼动唐国梁在进球瞬间的全场不在场证明。终场哨响，唐国梁作为店方代表留守，陈拾被带回派出所留置室。深夜十一点过，值班室的小电视重播中阿之战第36分钟，陈拾隔着铁栏杆，终于看清了于根伟把球打进的那一脚。 |
| `E_RUN` | **人潮** | ch3 末绝境选择翻窗逃跑 | 陈拾从窄廊气窗翻入后巷，一路跑到人民南路。终场哨响时，上万涌向天府广场的球迷、喇叭与国旗瞬间将他吞没。身后没有警笛追上来，但他知道，从自己翻出窗台的那一秒起，柜里的箱子、桌上的钥匙和便签上那两行字，就再也洗不清了。 |
