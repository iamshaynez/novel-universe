# ch4-slum
@bg factory-yard time=day
@date 二〇〇三年十一月十五日 · 上午十点
@fact pub-1997-soe

沙河东侧的铁合金厂宿舍区，已在拆迁推土机的轰鸣声中沦为一片断壁残垣。
宋明根据献血证背面模糊的铅笔手写地址，摸进了一处建在防空洞入口处的半地下棚户。
霉味、烂菜叶与廉价煤油的气味在幽暗的通道里凝结成实质。
一扇用烂胶合板拼成的矮门，虚掩着一根发锈的细铁丝。
这就是刘亮生前住了三年的地方。
不到六平米的单间，一张用红砖支起来的折叠床，床脚堆着几只洗得发白的塑料油漆桶。
桌上除了一只缺了口的搪瓷缸，便是厚厚一叠泛黄的医院缴费收据——
华西医院肾内科透析单，每一张上都盖着鲜红的「现金付讫」，金额从三百到八百不等。
而在床头最显眼的地方，端端正正摆着一张黑白遗照。
遗照里的老工人穿着八十年代的深蓝翻领工服，胸前别着一枚铜制内燃机厂厂徽，面容清瘦沧桑。
宋明的目光扫过那张照片，整个人如遭雷殛，僵死在原地。
那张脸……他在十年前见过。

# ch4-basement
@bg factory-yard time=day
@peak inner

宋明发疯般地掀起发霉的被褥，一把掀开床板底下的夹层。
灰尘呛得他剧烈咳嗽。
在两块干燥的旧报纸中间，压着一份用红塑料袋精心包裹的文件。
那是厚厚一本一九九七年国营成都内燃机厂的《改制分流下岗人员终审审批名册》。
翻开第一页。
铸造车间首批下岗安置名单第一行，赫然用黑墨水写着三个字：
「刘建国，工龄二十八年，四级翻砂工，核定下岗买断。」
而在那一页右下角「工会职工权益审查委员会」的签字栏里，签着一个宋明刻骨铭心的名字——
「审核工会干事：宋明」。
一九九七年秋天的东郊大下岗，内燃机厂两千名工人分流，名额只有一个宽限指标。
当年为了保全自己不成器的小舅子留在总装车间，宋明在深夜的评审表上，亲手划掉了身患慢性肺气肿的老翻砂工刘建国。
刘建国下岗后拿不到厂医保，两年后在廉租房里咳血身亡；
少年的刘亮被迫辍学，在汽修厂烫坏了嗓子成了哑巴，为了给寡母挣一口透析的活命钱，像牲口一样在东郊的车库里给韩荣洗车看门；
然后，在二〇〇三年十一月十二日的暴雨夜里……
宋明站在六米高的铁梁上，亲手抽掉绳索，用二十五公斤的生铁滑轮，砸碎了这个老翻砂工唯一儿子的脑袋。

# ch4-karma
@bg factory-yard time=day

宋明双膝一软，重重跪倒在潮湿冰冷的水泥地上。
他死死捂住胸口，喉咙里发出困兽般痛苦而沙哑的干呕。
因果在时代的泥潭里兜转了整整六年，化作一道冰冷的回旋镖，毫厘不差地凿穿了他的咽喉。
他算计了一辈子，小心了一辈子，自诩为一个凭双手吃饭、清白干净的手艺人。
他以为自己在东郊泵站完成的是一场悲壮的正义私刑。
可真相何其残忍——
他早在六年前，就亲手抽掉了刘家房梁上的第一根顶梁柱；
六年后，他更是成了恶霸手里一把涂满毒药的快刀，把这个在泥沼里苦苦挣扎的苦命家庭彻底斩草除根！
他不是什么抗击恶霸的受害者。
他就是这片丛林里吞噬弱小的那条恶犬。

# ch4-archive
@bg factory-yard time=day
@date 下午两点
@set has_scar_archive

从防空洞出来，宋明抹净了脸上的冷汗与泪痕。
他的脊背比任何时候挺得都要直，眼神里那种工匠特有的偏执被淬炼成了一种决绝的死志。
他骑车穿过建设路，来到内燃机厂留守处那间即将腾退的工伤档案室。
老管库员是他的老相识，递了一包大前门，宋明翻开了落满石灰灰尘的一九八三年工伤记录簿。
在厚厚的牛皮纸卡片里，他抽出了韩荣当年的《因公负伤治疗鉴定表》。
上面附着一张工伤鉴定的黑白特写照片，以及厂医院外科的诊断证明：
「一九八三年七月，韩荣同志在热处理车间操作交流弧焊机时发生电弧飞溅，右小臂内侧遭受三度深层电弧灼伤，真皮全层坏死，形成八公分乘四公分之菱形永久性增生瘢痕，终身无法平复。」
宋明将那张薄薄的工伤卡折叠整齐，放入内衣贴着胸口的口袋。
今晚九点，火车北站。
老韩戴着假发、口罩，拿着买来的假身份证，以为自己可以踩着一个哑巴少年的尸体、带着上千万黑钱远走高飞。
他以为全天下没有人能戳穿一个死人的复活。
但他算漏了一件事——
杀人的刀是有记忆的。
握刀的人，要亲自去斩断这根锁链。
