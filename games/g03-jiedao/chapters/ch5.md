# ch5-north-station
@bg north-station time=night
@date 二〇〇三年十一月十四日 · 晚九点

深秋的浓雾笼罩了整个成都火车北站广场。
二环路高架桥下的车灯在雾气里拉出昏黄的光带，进站口大楼顶端「成都」两个巨大的霓虹红字在夜雾中明明灭灭。
非典过后的第一个深秋，进站广场东西两侧依然支着蓝白帆布的防疫测温棚，背着红白蓝蛇皮口袋的民工与旅客在铁马护栏间排起长龙，绿皮火车的汽笛声隔着站台远远传来。
宋明穿着那件洗得发白的深灰工装棉袄，左手拎着那只装满五百万不记名国库券的黑色人造革公文箱，一步步走过湿滑的水泥广场。
他的右衣兜里，揣着五金铺里用了二十年的那把半圆形修鞋割皮刀；左胸内袋里，贴着刘亮的《四川省无偿献血证》与韩荣一九八三年的《因公负伤治疗鉴定表》。
在进站口右侧那排报刊亭的背光阴影里，一个头戴翻耳棉帽、脸上捂着厚白纱布口罩的微驼老汉正靠在铁栏杆边。
看见宋明走近，老汉浑浊的眼珠在帽檐下转了一圈，右手伸进棉袄口袋，拇指在黄铜打火机砂轮上轻轻括了三下。
「咔嗒、咔嗒、咔嗒。」

# ch5-rendezvous
@bg north-station time=night

宋明在离他两步远的地方停下脚步。
白纱布口罩底下传出那阵熟悉的旱烟干咳，声音压得很低：
韩荣：「宋老哥，守时。箱子带来了？」
宋明低头看了一眼手里的黑皮箱：「五百万国库券，一张没少。」
韩荣满意地点了点头，把一张折叠的房产证抵押底单和一张五万元的工行定活两便存单夹在两指间晃了晃：
韩荣：「到底是老实手艺人，分得清轻重。今天下午四点，周翠兰已经签字把停尸房那具尸首送去东郊火葬场推进炉子了。再过四十分钟，K192次列车一过广元出川，这世上就再也没有融泰典当的韩荣了。我包里揣着顺兴茶铺九号桌替我从九八年东郊旧档里洗出来的『周建国』身份证，下半辈子去南方养老；你拿着房产证和存单回致民路继续修你的车、锉你的钥匙，这笔账你划算。」
韩荣伸出右手，袖口下隐约露出一角贴在右小臂内侧的黑色麝香止痛膏药：
韩荣：「把箱子递过来吧。这成都城每天成千上万的人进出北站，没人会在乎前天夜里死在排污沟里的哑巴叫什么名字。」

# ch5-truth
@bg north-station time=night
@peak split

宋明看着韩荣伸过来的那只右手，食指轻轻推了一下鼻梁上的钢丝眼镜。
宋明：「差一厘都不行。他叫刘亮，二十二岁，是内燃机厂四级翻砂工刘建国的儿子。」
话音未落，宋明左手猛地抡起那只沉甸甸的黑色公文箱，用尽全身力气朝三米外站前警务值班亭的玻璃窗砸了过去！
「哗啦——！」
钢化玻璃轰然碎裂，锁扣崩开的黑皮箱摔在值班民警的办公桌上，成捆的百元面额国库券撒了一地！
韩荣脸色大变，刚想缩手后退，宋明那只拧了二十年台虎钳的左手已经像铁箍一样死死扣住了他的右手腕，右手从棉袄兜里抽出那把半圆形修鞋割皮刀，刀刃顺着韩荣右小臂的棉袄袖管由下往上猛地一划！
棉布袖管连同那贴黑色止痛膏药应声裂开，刀尖在韩荣右小臂外侧划出一道血口！
韩荣痛得凄厉惨叫，白纱布口罩被宋明一把扯下，整个人被宋明用肩膀顶着重重掼倒在警务亭门口的水泥地上！
韩荣：「杀人啦！救命啊！这疯子拿刀抢劫杀人啦！」
刺耳的警哨声与拉动枪栓的咔哒声瞬间响成一片！
四五名执勤武警与巡警冲出岗亭，枪口齐刷刷对准地面。宋明不等警察近身，主动松开右手，让那把沾血的割皮刀当啷掉在水泥地上，双手反剪在背后，用膝盖死死压住地上挣扎的韩荣。
刚追查线索赶到北站进站口的何峥与老彭从人群外飞奔而来：「宋明？！你干什么？！」
宋明被两名巡警反铐住双腕，镜片在搏斗中碎了一只，他却仰起头，从左胸内袋里用下巴顶出那两张叠在一起的纸页，声音在寂静的北站广场上字字清晰：
宋明：「何警官，我投案自首。十一月十二日夜里九点三十二分，在东郊废弃泵站，是我用天车上的二十五公斤铸铁滑轮和自制黄铜快脱销，蓄意杀害了二十二岁的南充青年刘亮。凶器铜销和劳保手套就在我致民路五金铺台虎钳底座下。」
围观的旅客一片哗然。宋明被手铐勒出血印的双手高高举起，直指地上脸色惨白的男人：
宋明：「而你们停尸房里那具被周翠兰签字认领的尸体，根本不是韩荣！我胸口这本《四川省无偿献血证》是刘亮的，另一张是一九八三年内燃机厂的《因公负伤治疗鉴定表》！你们低头看地上这个揣着『周建国』假身份证的男人——他右小臂内侧刚刚被我划开的黑膏药底下，有一块八公分乘四公分的**菱形永久性增生瘢痕**！他才是欠了东郊三千户老百姓一千两百万集资款、买凶借刀杀害刘亮假死骗保的韩荣！」
何峥一步抢上前，按住地上男人的右小臂——在红蓝闪烁的警灯下，那块暗红色、呈标准菱形隆起的电弧焊永久增生瘢痕，与泛黄鉴定表上的黑白照片分毫不差！
人群外亮起一道清脆的相机闪光灯——正在北站广场暗访夜间票贩的《市民热线》记者许知微举着傻瓜相机，将韩荣右臂的菱形焊疤、散落一地的国库券与那张由「顺兴茶铺九号桌」洗出的假身份证定格在同一张底片上。
韩荣眼底最后一丝侥幸彻底塌成了死灰。在文庙后街的二道旧物铺里，沈彻终将替师父收好致民路明成五金最后那套双防滑槽什锦锉；而档案室的老彭与何峥，也将顺着这张假证背后的「九号桌」，掀开下一卷尘封的旧档。

# ch5-miss
@bg north-station time=night

宋明看着韩荣袖口下那角黑色止痛膏药，握着割皮刀的右手在棉袄兜里停了三秒钟，终究一点一点松开了力道。
他把那只装满五百万国库券的黑皮箱递了过去。
韩荣接过箱子，满意地一笑，将那张致民路房产证底单和五万元存单塞进宋明的外套口袋。
韩荣：「宋老哥，这就对了。人活一世，先顾眼前自家的热汤热饭，死人的名字值几个钱？」
韩荣提着黑皮箱转过身，汇入扛着蛇皮口袋的进站人流，很快消失在K192次列车的检票闸机后头。
宋明独自推着二八大杠自行车，穿过浓雾弥漫的二环路回到致民路。
房产证保住了，女儿的医药费有了着落，公安局的卷宗上，「韩荣遇害案」成了悬案，而刘亮这个名字就像一滴浑水渗进沙河泥底，再也没有人提起。
宋明依然每天早上八点半打开五金铺的木板门，守着满屋的轴承与台虎钳，替街坊修车、配锁，只是再也没有在任何一把黄铜钥匙肩上锉过那两道斜向防滑槽。
每逢深秋下雨的夜里，只要风吹动门外铁皮雨棚，他坐在煤炉边擦拭眼镜时，耳边总会清清楚楚地响起三声金属火机刮擦砂轮的脆响——
「咔嗒、咔嗒、咔嗒。」

# ch5-wrong
@bg north-station time=night

宋明一把丢开手里的黑皮箱，赤手空拳扑上去死死抱住韩荣的肩膀，朝着十米外的站前警务亭嘶声大喊：
宋明：「警察！抓人！韩荣没死！这个人是韩荣！他是假死的！」
广场上火车汽笛长鸣，排队进站的民工乱作一团。
韩荣早有防备，趁宋明没有动刀的瞬间，猛地解开宽大旧棉袄的盘扣，像泥鳅一样金蝉脱壳滑出棉袄袖管，一脚踢翻旁边的蛇皮口袋堆，仅用三秒钟便钻进拥挤的检票人潮里消失得无影无踪！
等两名巡警冲过来按住情绪失控的宋明时，宋明手里只剩下一件空荡荡的破棉袄和地上那只装满五百万国库券的黑皮箱。
宋明跪在水泥地上语无伦次地大喊「死在沙河里的人是哑巴刘亮，韩荣刚跑了」，却拿不出任何证明方才那个戴口罩老汉就是韩荣的伤痕铁证。
次日清晨，何峥带队搜查致民路明成五金铺，从台虎钳底座暗槽里搜出了带有东郊泵站天车链条咬痕的自制黄铜快脱销钉、沾有血迹的粗线劳保手套，以及那本原本属于洗车工刘亮的《四川省无偿献血证》；与此同时，融泰典当车库监控磁带也被匿名寄到了分局。
由于周翠兰已凭金戒指签字火化遗体，且办公室紫砂茶杯的八点指纹比对具有完全法律效力，法庭认定死者确系韩荣本人，而宋明关于「韩荣假死脱壳、死者实为刘亮」的供述被判定为蓄意杀人犯在赃款面前企图混淆视听的脱罪狡辩。
数月后，成都市中级人民法院以**故意杀害韩荣**罪判处宋明死刑。直至走上刑场的那一刻，那座墓碑上刻着的依然是恶霸韩荣的名字，而二十二岁的刘亮终究沦为了这世上无人知晓的孤魂。
