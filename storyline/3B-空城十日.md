# 《空城十日》

**开场即结局**：2003-05-20 的报纸版面——照片里戴口罩的女人背影立于空旷的春熙路口，标题《非典时期的爱情：她等到了他》。

**P0 叙述框架声明（逻辑型 + 事后叙述）**：整个游戏是摄影师简一在 5-20 之后的**四次讲述**（对报社、对她父母、对警局、对自己）——不可靠的不是线索，是叙述框架本身。

**表面（第一次讲述）**：女人的恋人滞留外地隔离中，托简一带一样东西给她。十日穿城：锁门的小酒馆、空荡的教室、北站停开的候车厅、深夜仍亮灯的半夜面（望哥：「空城？我的店只在半夜开，本来就没什么人」）。5-20 她在路口等到了他，快门按下，新闻诞生。

**四重解释（同一张照片）**：
- **A 爱情版**——她等到了他。
- **B 解禁版**——她等的是"城开"的那一声广播，照片拍下的是广播响起的瞬间。
- **C 共谋版**——恋人根本不存在，是她讲给父母听的虚构；空城十日没有第三个人能拆穿，而简一是知情的共谋。
- **D 私奔版（隐藏）**——恋人真实存在，5-20 借简一的手机通话定下出城之约，电话亭通话记录是钥匙。

**公平钥匙**：委托物是两张 4-18 的车票（送达时已过期）；她的传呼机只响过一次；电话亭记录；口罩下的呼吸节奏。恋人的一切接触必须媒介化（字条/电话，且每次都可两读），进释放矩阵 ✗ 列写明保证物。

**纪律自查**：非典仅作空城氛围（成都病例寥寥）；四版翻转点全部落在人际（票/广播/谎言/电话），不涉病亡、不作诡计核心、不消费苦难。报纸版面标题虚构化，报方是受害者不是同谋。

**四结局 = 对同一张照片的四重最终旁白。**

## 评审记录

- 修复采纳：事后叙述框架（P0 声明使 C 版的不可靠叙述合法化）；媒介化接触进矩阵 ✗ 列（保证物=字条/电话两类载体）；报方为受害者、版面虚构化；B 版「等的是解禁广播」已是纪律边界内最贴的一格，不得再进一步。
