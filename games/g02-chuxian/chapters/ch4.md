# g02-second-half
@bg houzimen-billiards time=night
@date 下半时

阿曼的球一次贴着我们门柱出去，前堂响起一片倒吸气。
陈拾也回头了。他只看了一眼，就又把脸转回来。
何峥：「你现在还在看球？」
陈拾：「我看不懂了。」
何峥：「什么看不懂？」
陈拾：「你们说有人杀完人，把箱子放到我柜里。可冯老板死以前，已经在准备报失。到底哪一个是先的？」
何峥：「这也是我们要查的。你还有机会把自己放在哪个位置说清楚。」
陈拾看着后头窄廊。柜子已经开过，现金箱已经取走，柜门现在一推就开。
唐国梁在吧台边回答另一个民警的问题。他说自己出来以后一直在前堂，没有回去过，也没有碰过陈拾的柜子。
何峥：「你打算继续说巧合，还是把开柜的过程再讲一遍？」

* 让何警官再开一次柜，慢慢想哪一步不对。 -> g02-reopen-locker
* 直接说出开球前柜门被硬物顶住。 -> g02-locker-time

# g02-reopen-locker
@set reopen_locker
陈拾把空柜门拉开，又合上。
没有围裙，没有纸巾，柜门现在轻得很。他用膝盖顶了一下，门板直接碰上了。
就是这一下，让他想起开球前。
陈拾：「不是现在这样的。开球前，它关不上。」
何峥：「什么关不上？」
陈拾：「柜门。被里面硬东西顶到。我用膝盖顶进去的，还响了一声。」
-> g02-locker-time

# g02-locker-time
@set told_locker
陈拾：「开球前，我放围裙的时候，柜门就被东西顶住了。」
何峥：「你看清楚是什么没有？」
陈拾：「没有。我以为是球鞋或者擦杆布。赵伯喊我看球，我就锁了。」
何峥：「几点？」
陈拾：「七点过。首发还没出来。」
何峥：「箱子有多大，你刚刚看见了。能不能把你柜门顶住？」
陈拾：「能。」
-> g02-timeline

# g02-timeline
@date 下半时中段
@bg houzimen-billiards time=night

何峥让人把陈拾第一次开锁、取箱的过程重新问了一遍，又找了赛前见过他锁柜的人。
没人看见箱子，却有人记得陈拾用膝盖顶过柜门，还被赵伯催了一句。
何峥：「如果开球前箱子已经在里面，那就不是冯世昌死后谁才放进去的。」
陈拾：「所以杀他的人，不一定想好了要栽给我。」
何峥：「也可能还是他早就在准备。但我们要把动作分开：箱子什么时候进柜，冯世昌什么时候死，我们什么时候发现。」
唐国梁站在不远处，听到这里，只说了一句。
唐国梁：「我没往他柜里放过东西。你们现在问的是哪个先，我也想知道。」
他没有抢着说「我早就告诉过你」，也没有主动把冯世昌的计划全认下来。
陈拾看着现金箱，忽然明白一件事，大家发现它的顺序，一直在替它编故事。
先看见尸体，再看见箱子，于是所有人都以为箱子是跟着尸体来的。
可它来得更早。

-> g02-before-final

# g02-before-final
@bg houzimen-billiards time=night

何峥把那张便签重新放到陈拾面前。
何峥：「箱子的时间可以先往前推。下一步，是冯世昌生前这套报失怎么来的，唐国梁在里面到底知道多少。」
陈拾：「如果我把我知道的都说出来，会不会更像一起做局的？」
何峥：「像不像，不由你少说两句来决定。你只负责说真话，怎么核是我们的工作。」
陈拾：「要是我还有没说过的？」
何峥：「现在说。还来得及。」
陈拾看着便签上自己的两行字。它已经不是一张盘账纸，是能把老板生前的安排和经理生前的话接起来的东西。
前堂有人喊时间不多。骆师傅看了眼门外，说终场以后街上一窝蜂，谁要走都不好找。
唐国梁也听见了。他把椅背上的外套拿下来，搭在手臂上。
