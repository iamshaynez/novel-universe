# 五章结构与行动坡度

## 总体拓扑与设计原则

- **单夜球赛时钟（HUD `@date` 驱动）**：五章严格对应 2001-10-07 中阿之战的五个时段（赛前至第36分钟 → 上半时尾声 → 中场休息 → 下半时 → 终场哨前与散场）。
- **让读者先赢一局小的，再输掉一局大的，最后亲手翻盘**：
  - ch2 末读者凭“开球前柜门顶住”看穿现金箱早就在柜里（小胜）；
  - ch3 翻出死者生前假失窃与陈拾亲笔便签，叠加“进球时间”公共钟与骆师傅罚单，陈拾陷入“同谋内讧杀人”的灭顶绝境（大败）；
  - ch4 陈拾背对屏幕，通过「对表」与物理微痕（打翻热茶、折断墨笔、震动磨印）拆穿第36分钟公共钟（主诡计大翻盘）；
  - ch5 拆穿“谁是白球（计划作者）”，并在终场哨响、警力抽调去天府广场的死线前，完成“可信度＝说全”的终极抉择。

## ch1《开球》（18:30 至上半时第36分钟）

- **场景与节拍**：
  1. `g02-kickoff`（18:30）：后子门台球厅赛前预热。电视被唐国梁从下午起挪到堂心（绷紧插线板暗扣，埋下备用断电预案）；赵伯念叨全兴与马儿；温荟坐在吧台边频频看座机和门口（等同学电话）；骆师傅把出租车停在街边。
  2. `g02-pager-habit`（18:47）：冯世昌腰间汉显机响，两分钟内从器材室出来到吧台用座机回电（立下“汉显机+座机、三分钟必回”的私人钟习惯；去数据科普化，以磨损字迹与账板正字替代）。冯世昌顺口让陈拾今晚八点提前打卡下班看球。唐国梁叫住冯世昌低语两句，冯世昌在班次本添字——**陈拾没听见内容，只当老板和经理照顾自己**。
  3. **选择点 1（观察分支）**：
     - `* 先把里头两张球台收干净，省得明天挨说。` → `g02-finish-tables`（置 `@set finished_tables`）：唐国梁过来帮陈拾压平球杆，顺手教他打一杆组合球（**“打前头那颗，让它替你送。白球停住就对了，白球最忌讳跟着进去”**）。
     - `* 先凑到电视机前头，听赵伯摆首发名单。` → `g02-listen-zhao`（置 `@set listened_zhao`）：赵伯讲马儿、祁宏停赛与于根伟首发，唐国梁在旁边擦杆，随口拿球台上的组合球打比方（同样埋下“白球最忌讳跟着进去”的主干台词，确保主干保底）。
  4. `g02-locker`（19:05）：陈拾去窄廊塞围裙，柜门被里面硬物顶住，他用膝盖顶上锁好。摸着师兄沈彻赠予的明成双防滑槽黄铜钥坯，铭记手艺规矩。
  5. `g02-pregame`（19:30 开球）：中国队白衣开球。19:45 冯世昌泡了一杯热浓茶与唐国梁进器材室“盘账”，吧台交陈拾看管。
  6. `g02-call-1958`（19:58，「一拦」）：骆师傅刚换完零钱出门挪车。吧台座机骤响，温荟第一个站起来（以为是同学，失望坐下）。陈拾接起，是冯家问“呼了他两遍咋不回电话”。陈拾正要去器材室喊人，唐国梁从窄廊走出来按住话筒拦下他：“莫去，他在里头对着旧账发火，等哈我跟他说。”唐国梁手心发冷。
  7. `g02-goal`（20:06 上半时第36分钟，「一送」与借势峰值）：于根伟破门！**唐国梁顺水推舟抓住这脚世纪射门，在堂心一把抱起赵伯转了半圈**，全场沸腾。欢呼稍落，唐国梁拍陈拾后背：“去，拿盒新皮头，顺便给冯老板报个喜，把他屋头来电话的事也说了。”陈拾推开器材室门，手电光照见冯世昌后脑的血（`@peak dead`）。

## ch2《一比零》（20:20 至上半时结束）

- **场景与节拍**：
  1. `g02-police`（20:22）：何峥带民警到场封锁前后门。初检发现打翻的热浓茶浸透账簿边缘，水泥地上有折断的钢笔尖与拖痕。对讲机里通报终场后天府广场方向的执勤预案。唐国梁沉稳配合，随口说出**“进球那阵堂子里吵成那样，里头就是喊破喉咙外头也听不见”**——把所有人的记忆锚死在 20:06 公共钟上。
  2. `g02-keys`（20:35）：后门内闩锁死，打卡纸显示陈拾八点整下班，进球时无人能证明陈拾在吧台。唐国梁“好心”替陈拾担保老实，却顺口道出“兼职柜里挂着器材室备用钥匙”。
  3. **选择点 2（诚信档案一：钥匙交接）**：
     - `* 把钥匙交接的规矩和今晚谁进出过窄廊全说清楚。` → `g02-keys-full`（`@set told_keys`）
     - `* 先只认柜子是自己的，钥匙的事推说还没交接。` → `g02-keys-hide`（`@set hid_keys`，唐国梁立刻递上交接本，陈拾第一次体会到“少说一句反而让纸面更完整”）。
  4. `g02-pockets`（20:45，口袋里的纸与遗物清点）：何峥清点众人随身时段凭证与死者遗物。骆师傅掏出 20:04 街边违章停车罚单；温荟捏着没用上的电影票根，手指因惊惧发白；唐国梁口袋里有一张次日北站预售车票（轻描淡写说是屋头私事）；冯世昌腰间取下那台摩托罗拉汉显机（屏幕亮着未读提示）与账本。
  5. `g02-ledger-search`（20:52）：吧台 4,760 元营业款现金箱失踪。何峥逐一开柜，陈拾柜门弹开，围裙深处赫然放着现金箱（`@peak desk`）。陈拾想起开球前顶住柜门的那一下，却明白此刻空口无凭。

## ch3《中场》（中场休息，十五分钟绝境）

- **场景与节拍**：
  1. `g02-halftime`：中场休息，堂内气氛凝滞。何峥追问器材室盘账内容，唐国梁点出“账面有出入，两万八千六”。
  2. `g02-shift-note`：班次表“陈拾请早退”与夹在账本里的便签翻出。便签正面写着假失窃计划，背面写着“28600 唐经手”。何峥指出假失窃，质问为什么中间两行“钥匙、柜”是陈拾笔迹。
  3. **选择点 3（诚信档案二：便签笔迹）**：
     - `* 承认中间两行是几天前帮冯老板抄的，把经过说出来。` → `g02-copy-full`（`@set told_copy`）
     - `* 咬牙否认，说没见过这张纸，免得被当成同谋。` → `g02-copy-hide`（`@set hid_copy`）
  4. `g02-old-accounts`（`@fact ev-g02-fake-theft`）：何峥拼出“同谋分赃不均杀人”的嫌疑链——在 20:06 进球这口公共钟下，唐国梁正抱着赵伯欢呼，骆师傅有 20:04 罚单，全店只剩陈拾有钥匙、赃箱、亲笔便签且无不在场证明。
  5. `g02-zhaobo-1995`：下半时即将开球。何峥翻动黄历便签沙沙作响，唐国梁下意识捏紧鹿皮擦杆布；赵伯受具象刺激触动，想起 1995 年成都保卫成都翟飚头球（只记进球一秒），并猛然唤醒记忆残片：“对不上就说遭贼，年轻人说不清——前两天也是这间屋、拿着擦布说的……”
  6. **选择点 4（中场绝境：留下来对表 vs 翻窗逃跑）**：
     - `* 不跑。把脸从电视机那边转回来，留在堂子里把时间一分钟一分钟算清楚。` → `g02-stay`（进入 ch4）
     - `* 绝境下害怕当场被铐走毁掉一生，想趁乱翻窗回北门家里取烟盒原稿自证。` → `E_RUN`（进入悲剧逃跑结局《人潮》）

## ch4《下半场》（主诡计章：背对屏幕与物理微痕对表）

- **场景与节拍**：
  1. `g02-second-half`：下半时开球，阿曼射门擦柱而出。陈拾彻底**背对电视屏幕**。牛仔衣后生质疑，温荟冷静中立作证。
  2. **选择点 5（拆第一重锁：柜门与现金箱时间）**：
     - `* 请何警官带自己回窄廊，把空柜门重新开关一次。` → `g02-reopen-locker`（`@set reopen_locker`）
     - `* 直接说出七点零五分开球前柜门就被硬物顶住、赵伯在外头催看首发。` → `g02-locker-time`
     - （合流置 `@set told_locker`：赵伯证实开球前听见陈拾顶柜门。现金箱入柜时间前推至开球前，拆掉“杀人后栽赃”）。
  3. `g02-pager-inspect`（触发私人钟与物理锁）：何峥指出不能排除 20:06 进球杀人。陈拾要求核对汉显机。屏幕点亮两条未读——`19:52` 与 `19:57`。
  4. **选择点 6（「对表」推理第一问：私人钟与身体直觉）**：
     - `* 陈拾吐露身体记忆：冯老板铁公鸡三分钟必回座机，七点五十二分就已经回不了电话！` → `g02-clock-step2`
     - `* 产生自我怀疑：会不会是吵架赌气没顾上？` → `g02-clock-hint1`（唐国梁接话打压，陈拾迅速凭借 18:50 亲眼所见重回正轨）
  5. **选择点 7（「对表」推理决胜问：死亡时刻到底在何时？）**：
     - `* 死在七点五十前后！何峥戴手套复核打翻浓茶、折断墨笔与死者后腰墙角受压震动磨印，物理三锁闭环！` → `g02-two-clocks-solved`（`@set time_solved`）
     - `* 被全场狂欢记忆与唐国梁言语霸凌彻底催眠动摇（Gaslighting）。` → `g02-clock-retry`
       - 二次选择：
         - `* 惊醒算反了！物理微痕骗不了人，死在进球前！` → `g02-two-clocks-solved`（`@set time_solved`）
         - `* 意志崩溃，顺从公共钟记忆。` → `E_WRONG`（进入迷失结局《重播》）
  6. `g02-two-clocks-solved`（`@peak split`，物理硬锁锁定）：
     - 温荟作证 19:58 电话与唐国梁出窄廊拦人；骆师傅证实 19:55 换零钱时唐在室内。
     - 何峥复核确认：死者后腰水泥墙角震动擦痕与 19:52 呼机震动时长完全相吻，死亡窗口死死锁在 19:50–19:58，唐国梁不在场证明彻底崩塌！

## ch5《终场》（终场哨前对峙、时代深渊与可信度终局）

- **场景与节拍**：
  1. `g02-final`（温荟证实谎言）：唐国梁狡辩，温荟证实赛前其曾说“小陈来求过早退”。
  2. `g02-zhaobo-truth`（赵伯指认假失窃源头）：赵伯彻底想通，指认前天正是唐国梁递出“遭贼”和“小陈”的主意。
  3. `g02-plan-author`（`@fact ev-g02-fengshichang`，白球落袋）：何峥亮出三天前预售票。唐国梁深褐夹克下的时代创伤与九号桌赌球深渊暴露；陈拾回敬“白球最忌讳跟着进去，七点五十二分白球落袋”（`@peak inner`）。
  4. `g02-credibility-clash`（终场死线与反扑）：唐国梁抓住最后两分钟反扑陈拾诚信档案。
  5. **诚信档案分流（`if hid_copy` vs `if told_copy`）**：
     - 路线 A（`if hid_copy`）→ `g02-dilemma-hid`
     - 路线 B（`if told_copy`）→ `g02-dilemma-told`（唐国梁抛出私下交易）
  6. **选择点 8（终局抉择：说全 vs 散场）**：
     - `* 拒绝交易，将便签原稿、帮抄原委与今晚私心全部签字说全！` → `E_FULL`
     - `* 到此为止，保住自己，任由唐国梁趁乱退入狂欢人流。` → `E_LEAVE`

## 四个结局的文学回响

- `E_FULL`《说全》：唐国梁被铐走；何峥下令调取九号桌底单；陈拾逆着天府广场两万狂欢人流走向派出所车；街头闪过许知微采访车擦肩。陈拾手中捧着赵伯塞的凉茶，虽背负处分风险，却真正守住了手艺人的一身清白。
- `E_LEAVE`《散场》：何峥证据链缺最后一环，唐国梁搭着洗得发挺的深褐夹克迈出门槛，融入沸腾国旗人海。温荟收拾书包留下克制的凝视。陈拾保住了毕业证，却一辈子手里攥着那半张不敢交出的真话。
- `E_WRONG`《重播》：被群体狂热记忆同化洗脑的陈拾，深夜在派出所铁栏后看电视重播第36分钟于根伟的进球。
- `E_RUN`《人潮》：恐惧体制与刑拘的少年翻出后巷，被上万欢呼的人潮吞没，亲手把自己铸成了逃犯。
