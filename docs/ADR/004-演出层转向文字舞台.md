# ADR-004 演出层转向文字舞台

日期:2026-10-23　状态:已接受

## 决策

演出层从 galgame 范式(背景图 + 立绘 + 底部对话框)转向**文字舞台**:排版即运镜,
文字本身是视觉对象,实体类型(人物/地点/时间/线索)各有一套视觉签名。

- 前后端一体框架全保留:纯函数引擎、服务端驱动、sqlite 存档、迁移纪律、TDD 流程。
- 删除旧演出栈:`web/` 旧播放器、`assets/`(chibi 立绘 / scenes 全景绘制 / scores 乐谱)、
  `tools/render-bgm.mjs`、`style-tests/` 归档;DSL 移除 `@show` / `@hide` / `@bgm`
  (编译器按「未知指令」拒绝,旧剧本自然显式报错);正典移除 `chibi` / `scene_file` /
  `score` 字段,canon 0.1.0 → 0.2.0(0.x 阶段破坏性按 minor)。
- 新正典字段:人物 `stage { side: left|right, theme }`(分侧站位 + 主题色,voice_hz 继续承担
  声线);地点 `mood { palette, rain, sign, bigchar }`(氛围层参数)。
- 概念验证(已删除的 typo-stage-demo.html)验证了完整演出词汇,证据截图见
  `docs/演出证据/`。

## 舞台合同 v0(本轮落地)

- IR 附 **canon 摘要块** `ir.canon = { world, characters[], locations[], events[] }`,
  按 `assumes ∪ {本作}` 做**纪元过滤**——演出层一次拿到所需数据,且不泄未来正典。
- view 合同收敛为 `aview = { bg: { id, params } }`;角色以**台词登场**。
- 播放器(`web/` 四件套:index.html / stage.mjs 词汇模块 / player.mjs 差分循环 /
  audio.mjs 合成音效)**状态差分渲染**,全部由 IR + canon 自动推导,剧本零演出标注:
  - chapter 变 → 清场 + 竖排章节卡
  - bg 变 → 氛围层切换(场景配方降级为氛围参数)+ 地点印章
  - 新说话者 → 声纹人物卡(voice_hz 生成波形签名)+ 分侧锚点
  - `fact.*` 新增 → 时间轴带点亮 + 线索解锁
  - 台词 → 呼吸单元节奏(标点驱动)+ 声线 blip;选择 → 分支生长;结局 → 收集
- 手工层特效(信纸开场 / 红笔圈词 / 坠落汉字 / 聚光灯 / 红绳连线 / 台词截断)
  **不在 v0 合同内**,demo 代码为参照实现,待 DSL 舞台指令(如 `@peak` `@letter`)
  设计后进入 v1。

## 舞台合同 v1 首片（2026-10-24 增补：@peak 峰值指令 + 播种层声纹法证）

**播种要静，回报要响。** 揭秘的响度是稀缺资源：公平线索以安静的方式长期摆在界面里，
峰值演出只给回报拍，不给播种拍——否则满屏都在喊，就没有惊讶了。

- **声纹法证（播种层）**：转写卡与底单回看的呼入者名旁带迷你声纹波。登典呼入者
  （callerChar 绑定）用正典 `voice_hz`，未登典者用名字确定性哈希伪声纹（无「有档/无档」
  元泄漏）；**不标 Hz 数字**——形状即线索，数字到证物拍回报时才出现。防泄底铁律不变
  （ADR-005 §3）：呼入波形中性墨，个体色仍只属于正在说话的人。
- **宇宙客串签名 `eu`**：`class: universe` 人物的行内签名（金墨骑缝 + 灯箱式闪现入场），
  由 canon 摘要块的 `class` 字段自动推导——永不主角者以传闻与边缘在场隐藏于行文。
- **`@peak <kind> [args]`（回报拍）**：词表六项，全部由 web 舞台词汇实现，剧本只标记：
  | kind | 拍 | 演出 |
  |---|---|---|
  | `inner` | 内声拍 | 全游戏唯一带声音的叙述行：玩家声线短波 + 双 blip + 浓墨底带慢入场 |
  | `dead [stamp]` | 死单拍 | 转写回执朱砂化 + 戏中时间戳 + 氛围压暗 + 呼机双短音（audio.page） |
  | `desk <tids>` | 证物拍 | 玩家转过的底单并排成案：caller·波形·Hz·留言，相同声纹依次点亮朱砂 |
  | `collapse <tids>` | 并轨拍 | 四条呼入波形从四角滑入叠合为一根（四声 blip 收敛为一声） |
  | `retype <词>` | 复键拍 | 键出→朱线划除→重打——「最该停下来的半秒钟」 |
  | `split` | 分身拍 | 首拍签条中性墨起笔、个体色慢渗入（你→她代词分裂在排版层可见） |
- **演出预算 lint 落地**（偿还原债 4 / ADR-005 债 2 的首片）：`tools/content-lint.mjs`
  `checkPeaks`——词表封闭（`PEAK_KINDS` 与 web 镜像）、每章 ≤3、全作 ≤8、峰值只落停点。
- 降级路径：未知 kind 安静降级为普通拍（lint 拦截于提交前）；`prefers-reduced-motion`
  下峰值动效退化为快速淡入；`?auto=1` 冒烟全部短路。
