## 解题链（最小知识集）

1. **第一链（拆掉“命案后栽赃”）**：`L03 开球前柜门被硬物顶住` + `L06 柜中搜出 4,760 元现金箱` → **推断 I1：现金箱在开球前（19:05）已入柜，栽赃早于命案**。
2. **第二链（翻出“生前假失窃與同谋嫌疑”）**：`L01 提前八点下班` + `L09 班次页“陈拾请早退”` + `L07 便签（含陈拾亲笔抄写的“钥匙、柜”与背面“28600 唐经手”）` → **推断 I2：冯世昌生前准备假失窃栽赃陈拾，并诱使陈拾留下笔迹；但警方据此怀疑陈拾是盗窃同谋、分赃不均杀人**。
3. **第三链（主诡计「两只钟」：拆掉唐国梁的进球不在场证明）**：`L13 冯世昌汉显机必在三分钟内到吧台回电` + `L17 死者腰间汉显机停在 19:52/19:57 两条未读` + `L14 19:58 冯家打进吧台座机，唐国梁走出窄廊拦下陈拾“莫去打搅”` + `L18 温荟因等同学电话在 19:58 起身，确认此时远在进球前且陈拾一直在吧台` + `L16 20:07 进球后唐国梁差遣陈拾进器材室报喜` → **推断 I3：冯世昌死于 19:50 前后（私人钟），而非 20:06 进球时（公共钟）；唐国梁用“一拦一送”推迟尸体发现时间，把全场欢呼变成自己的不在场证明**。
4. **第四链（终极翻转：谁是母球/计划作者）**：`L19 唐国梁台球课“打前头那颗，白球停住”` + `L10 温荟听见唐国梁对冯世昌谎称“小陈来求过早退”` + `L11 赵伯听见唐国梁先说“对不上就说遭贼，年轻人说不清”` + `L12 唐国梁提前买好的北站车票` + `L07 陈拾交出便签原稿并说全经过` → **推断 I4：冯世昌只是纸面上的物理作者（红球），唐国梁才是递出主意、目标并动手杀人的最初作者（白球）**。

## 公平性与红鲱鱼回收纪律

1. **严禁第一章越视角泄底**：ch1 绝不写出唐国梁对冯世昌说“小陈来求过早退”的台词，陈拾只看见唐国梁凑在冯世昌耳边说了句什么、冯世昌随即在班次本上添字，陈拾还以为是在夸自己手脚快。
2. **「两只钟」的全部零件在 ch1–ch2 主干必给**：冯老板 18:50 汉显机回电（L13）、19:58 吧台电话与唐经理拦人（L14）、温荟起身（L18）、进球抱赵伯（L15）、唐经理差陈拾报喜（L16）、死者遗物中的汉显机（L17），100% 位于主干必经节点，且第一次出场全部服务于日常看球与店堂生活。
3. **红鲱鱼回收**：
   - 误导一（骆师傅与 20:04 罚单）：ch3 用来封死“进球时其他人在场外”的可能，把陈拾逼到墙角；ch4 时间线前推至 19:50 后，骆师傅当时正在吧台跟陈拾换零钱，反而成为陈拾在吧台的旁证之一。
   - 误导二（唐国梁第36分钟的不在场证明）：ch1–ch3 越是铁证如山，ch4 对表翻面时“不在场证明本身就是推迟发现尸体的产物”就越惊艳。
4. **真结局不靠运气，靠推理与诚信闭环**：玩家在 ch4 通过「对表」亲手拆穿公共钟，在 ch5 通过直面自己的隐瞒（说全）补齐证据可信度。
