# chA3
@bg chuantai time=night
@date 十一月七日 · 凌晨

十一月七日，凌晨一点。
这一次，内袋里那本假证件没有派上用场——传达室的门卫换了个刚退伍的新人，正襟危坐地守着登记簿，非要看介绍信和钢印不可。这世上最难糊弄的永远是第一天上班的新人。
你没硬闯，退回街角绕到办公楼后身，顺着卸货的水泥斜坡摸上二楼。后廊消防梯的铁门闩还松松地挂着，倾斜的角度分毫不差，还是你前两回白天离开时拧松的那个位置。
底楼档案室的木门还是那扇。蹲下来借着打火机的微光一看，黄铜锁眼里，你白天拿发卡拨弄锁芯刮出的细痕还在。
你闪身进来，连气都没换，直奔十月末的那个铁皮柜格。
十月二十六——空着，不在。
跟六六八八转七沾边的纸，一页都不在了；当晚其余十几页不相干的底单，听老金的说法，前几天也被人整叠顺走了。

你大半夜翻窗进来，为的是确认另一件事：九月那一柜的旧底单，前几天到底有没有外人再来翻过。
你屏住呼吸，把九月柜格里的纸叠前前后后翻了两遍。
铁皮隔板积着的薄灰上，印着几道新的指印。按得不深，间距很稳，看得出来那双手翻检东西的时候慢条斯理，极有次序。
绝对不是小偷翻的。小偷摸进黑屋子总想捞把值钱的就跑，绝不会有闲心把每一摞底单的毛边拍齐了、再按原来的顺序放回去。
退回卸货斜坡的时候，你站在冷风里抬头看了一眼这栋黑漆漆的二层小楼。
这座城里还有另一个人，在顺走了十月二十六号的残页之后，又摸回来查九月份的旧账。而且单从手印来看，他翻东西比你稳得多，也干净得多。

刚走出巷子口，腰间的汉显机第三次震动起来。
@card koudai
这回不是姓王的尾号。你快步走到街口的玻璃公用电话亭，推门进去，插卡回电。
听筒里传出一个苍老、干涩的声音。老头没有寒暄，只对着话筒讲了短短两句——「你上次去店里留了号。」「四点，府南河桥头。」
啪嗒一声，那头挂了。电话亭的玻璃门上，你呼出的白气慢慢扩大成一团白雾，又在凌晨的冷空气里一点点缩回去。

# chA3-bridge
@bg funanhe-bank time=night

凌晨四点钟，府南河桥头。
河雾比上半夜更重，远处的路灯晕成一团团湿漉漉的黄球。一个穿旧劳动布工作服的老头蹲在桥头背风处烧纸。江风一阵紧似一阵，把烧成黑色的纸灰卷起来，旋了半圈，又贴着墨黑的水面低低地飞。
像一封一封没贴邮票、找不到收件人的信。
你在离他几步远的水泥墩子旁站住。老头往火堆里续着黄表纸，头也不回。

贺国栋：「你来了。」
「你找我来，想问啥子？」
贺国栋：「我问你，我女儿好端端的，为啥要走河对岸？」
他长年干钳工的双手布满老茧，指缝里还嵌着洗不掉的机油黑印，声音哑得像砂纸。
贺国栋：「她不会。对岸在修路，围挡立起，黑黢黢的。她一个女娃儿，夜头走那一边？」
一阵穿桥风刮过，火盆里的纸灰又腾起一群。
他伸手进工装怀里摸索了半天，掏出一只黑色的呼机。汉显屏，边角磕掉了一块，塑料壳上还带着他胸口捂出来的余温。
贺国栋：「她的。派出所退回来的。」
他用粗糙的大拇指按亮侧键，递到你面前。
幽绿的屏幕上，还是那一行字——
「十点，老地方，河对岸等你。就这样。」
半个月前被你亲手拿退格键删改过的字，此刻隔着一盆还没有烧尽的纸火，从死者父亲的手里，原封不动地亮给你看。
贺国栋：「十点。她十点三十五还在屋头打电话，她邻居听到的。她收到这条的时候，十点都过了。」
贺国栋抬起布满血丝的眼睛盯着你。
贺国栋：「你说，她看到这个，她急不急？」
你嘴唇动了动，答不上来。这世上没有人比你更知道这道算术题的答案是啥子。
贺国栋：「『就这样』——啥子叫就这样？」
你还是没有答。这三个字是谁留在四条留言末尾的句号，又是哪个坐台的把它敲进机子里的，你比谁都清楚。
贺国栋收回手，把那只磕破角的呼机重新贴着心口放好。
贺国栋：「除非，有人喊她过去。」

# chA3d
天亮之前，你钻进街角那座没人光顾的电话亭，把笔记本垫在冰凉的铝皮台面上。
档案柜里少掉的一叠底单、登记簿上撕掉的两页、派出所那位没登记名字的男老师、值班表上连守四个钟头的同一个名字、河对岸一脚宽的水泥沿——你把半个月走过的每一步，一条一条列下来。
列到最后，笔尖悬在纸上，落不下去。
这座城里，还有另一双手在跟你翻同一本账。而这本账翻到头，每一页都落在同一个名字上。

# chR4
@bg chuantai time=night
@date 十一月八日

十一月八日，立冬。
@set paper.drafts
更衣室狭窄的木头隔板上，你把藏好的十月二十六日原始底单、连同九月那两晚的转写底稿一字排开。
九月十四，陈先生，333-1188——「钱的事，再宽限几天。就这样。」
九月二十八，刘先生，901-7544——「东西准备好了，周六，老地方。就这样。」
十月二十六，333-1188——「别躲了。你爸签了字的。就这样。」
十月二十六，901-7544——「十点，老地方，河对岸等你。就这样。」
@peak desk t3,t4,t7,t9
四条跨越一个半月的留言，两个毫不相干的回电号码，同一个冷冰冰的句尾，外加同一声挂机前的轻咳。
@set paper.summary
你抽出一张白纸，先在背面画了一条竖线，分作左右两栏。左边，是那晚耳机里他讲给你听的——老地方，河对岸，等你到十二点。来不来，你自己定。右边，是你敲下回车键发出去的——十点，老地方，河对岸等你。两栏摆在一起，中间只差九个字。按台里的规矩，少打九个字，不过是帮打电话的人省了四毛五分钱。可这九个字一行一行，原本全是留给她的退路。
然后你把纸翻过来，在正面把这四条留言工工整整另抄成一张汇总表，用中华铅笔在四行字下面重重连了三道线。
接着，你闭上眼回忆耳机里的动静，照着记忆里的语速起伏，在纸边一笔一笔描出了四条声波似的折线——无论电话号码怎么换，那个人念到「就这样」三个字时的尾音抖法，简直像用同一个模子印出来的。
哪是啥子两父子、两兄弟。四条折线一个模子——从头到尾，怕就是同一个人，揣着两张不同的电话号牌在呼她。
薄薄一张纸，现在有了沉甸甸的两面：正面连着他换号催债的声纹，背面列着你删改字句的对照。

下午趁着没排班，你揣着这张纸去了一趟派出所。老彭正端着搪瓷保温杯吹茶叶沫子，抬头看见你——街口传呼台的小妹——先叹了口气。
老彭：「妹儿，结都结了的。家属都没意见。」
「留言可以作证。两个回电号，一个人的声——」
老彭：「声纹？我们这儿莫得那设备。你回去嘛。」
你扶着桌沿站在原地没动。老彭又叹了口气，慢吞吞地低头拨弄桌上的回形针，忽然想起什么似的抬起头。
老彭：「哦对了。前几天接连来过两位协查的老师，一男一女，都调过这本材料。我当时忙，搞忘喊他们登记名字了。」
你扶着桌沿的手指收紧了半分。
「男的那个，后来还来过没有？」
老彭：「来过一回。卷宗嘛，翻得最久的，是遗物登记那几页。」
窗外明明有太阳，你却觉得后脖颈一阵发麻，连指尖都凉了。遗物登记，那只磕破角的呼机，内勤抄在附页上的四条留言存稿。
他不是来查她咋个死的，他是冲着那几条留言来的。这笔账对到末尾，早晚会落到十月二十六号夜里守三号席的那个人头上。

# chR4-back
紧赶慢赶回到传呼台，天色已经擦黑，正是傍晚交接的时候。
你没有直接上二楼，而是顺着楼梯拐到底楼最里头，脚步在档案室门前猛地顿住。
生锈的黄铜锁眼里，清清楚楚多出了两道崭新的划痕。刚刮下来的细碎铜屑粘在锁孔边缘，在暗处还泛着一点金亮的光。
他已经来过了。
你看着那点发亮的铜屑，脑子里忽然冒出一个念头：这半个月里，这个不知名姓的男人像你的影子一样，在后面一扇门接一扇门地踩点、开锁、对账。
你一个人站在空荡荡的底楼走廊里，听见二楼机房传下来的按键声，夹着自己的心跳，一下，一下，密得像催命的五笔字根。

耳机扣上耳朵，全成都那些絮絮叨叨的长话依旧排着队流进来，又在你指尖被削成干干净净的短句。
