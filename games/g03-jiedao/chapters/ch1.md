# ch1-dawn
@bg banye-noodles time=night
@date 二〇〇三年十一月十二日 · 夜十点一刻
@fact pub-2003-sars

玉林北巷最深处的「半夜面」，红白塑料雨棚外头挂着一盏被水汽洇得发黄的灯箱，上头只写着一个手写的「面」字。
非典虽已过去小半年，巷口街道居委会的测温木台子依然架在风口上，红外测温枪在寒夜里闪着绿光。
宋明把挂着油布包的二八大杠撑在道牙边，脱下滴水的雨衣，将湿透的粗线劳保手套塞进车座下的工具包。
值守的防疫大姐拿额温枪对着他脑门嘀了一声：「三十六度四，正常。宋师傅，这么大个雨还出摊啊？签个字，写准几点进的巷子。」
宋明食指推了一下眼镜鼻梁，接过圆珠笔，在泛潮的防疫登记簿上工工整整写下：
「十一月十二日，二十二时十五分，宋明，住致民路五十七号。」
掀开厚棉门帘，一股滚烫的猪油混着熟花椒的香气扑面而来。
潇文系着黑围裙，正拿长竹筷在翻滚的骨汤锅里挑面。
潇文：「宋哥，来得巧，头锅棒子骨刚熬出白汤。老规矩，二两脆绍加个煎蛋？」
宋明在靠墙第二张方桌坐下，把冰凉的手掌贴在温热的粗瓷茶杯上。
宋明：「二两脆绍，蛋煎老一点，莫放葱。」
潇文把面盛进海碗端上桌，顺手抿了一口散酒，靠在灶台边摆起闲龙门阵。
潇文：「前两天文庙后街开二道旧物铺的沈彻那娃儿来吃面，跟报社跑《市民热线》的许知微许记者坐一桌，还问起你这个老师傅。」
潇文：「他们摆起九九年府南河那个音像店妹儿——一个说，是有人把传呼底单交上去翻了案；一个又说，是收账的自己想不通，磕了头去的。宋哥，这成都城的夜路，版本多得很。」
潇文：「对了，融泰典当最近怕是要出事哦——韩老板那边的债主，这几天把柜台都围脱了。」
宋明挑起一筷子细面，吹散白汽，慢慢咽下肚去。
从沙河东郊泵站骑车回玉林北巷，走正常大路至少要四十分钟；只有宋明自己清楚，他抄了内燃机厂废弃的铁路专用线涵洞，才在二十五分钟内赶到了这张面桌前。
头锅的热气糊上镜片。宋明取下眼镜，用袖口慢慢擦干净，重新戴好。
居委会的测温簿和潇文的头锅汤，把十点一刻的他钉在了这条巷子里。

# ch1-morning
@bg factory-yard time=day
@date 二〇〇三年十一月十三日 · 晨八点半
@set alibi_confirmed

清晨的冷光透过致民路五金铺的半截玻璃窗，照在满墙的什锦锉、游标卡尺和轴承套筒上。
宋明插上木门内栓，先把怀里焐了一夜的那张华西催缴单摸出来，压在台虎钳的砧座角上——宋雨下个礼拜的床位费，还差三百四十块。
然后他把昨晚从车库提回来的那只黑色人造革公文箱放上工作台，用挑针拨开了箱锁。
箱盖弹开，里面整整齐齐码着五捆未拆封的不记名国库券与两本定额存单，票面整整五百万；可箱底空空如也——两天前韩荣当着他的面压在箱底的那张四万块高利贷借据和他的房产证抵押底单，根本不在箱子里！
宋明眉头猛地拧紧。
他压下心头的不安，伸手从工装棉袄内兜里摸出昨晚在泵站从死者贴身夹层里抽出的那只透明塑料封套。
封套边缘粘着干涸发黑的血痂。宋明拿起修表用的扁嘴镊子，夹开塑料按扣，把里头的东西抽了出来。
没有借据，也没有韩荣的私章。
落在铁砧上的，是一本被泥水泡软了边角的红色薄塑皮小册子——
封面上印着一行烫金字：「四川省无偿献血证」。

# ch1-shock
@bg factory-yard time=day
@set has_blood_card
@peak inner

宋明手里的扁嘴镊子当啷一声掉在铁砧上。
他揭开粘连的扉页。
内页贴着一张一寸黑白免冠照，钢笔字迹被水洇开了一角，却依旧清晰可辨——
持证人一栏写着「**刘亮**」，男，**二十二岁**，血型为**B型**，发证日期是二〇〇三年三月。
照片上的年轻人剃着齐耳寸头，颧骨瘦削，穿着一件洗得发白的旧工装，从下巴颏一直到喉结下方，盘踞着一片凹凸不平的深色陈旧烫伤疤痕。
那双眼睛直直地望着镜头，带着一股乡下孩子初进城时的拘谨与老实。
刘亮。二十二岁。
宋明握着台虎钳摇柄的指节一寸寸发白，后背像贴上了一整块浸在冰水里的生铁板。
昨晚九点三十二分，穿着韩荣的黑色羊皮领大衣、拄着黄铜兽首手杖、在泵站长椅上连打三下火机的人——不是四十八岁的融泰典当老板韩荣。
是一个下巴带烫伤疤痕的二十二岁的年轻人。
而就在这时，五金铺外头的木板门被重重叩响了三下。
「咚、咚、咚。」
门外传来成华区分局刑警何峥沉稳的声音：「宋师傅，在铺子里没有？派出所的，开一下门。」

# ch1-hide-calm
@bg factory-yard time=day
@date 晨九点一刻

二十年钳工练出的稳劲压住了手心的冷汗。宋明左手一推，将那本《四川省无偿献血证》连同昨晚换下的黄铜快脱销钉一起塞进台虎钳底座的空心铁槽，右手抓起一块油棉纱在手背上擦了一把，拉开了木门栓。
门口站着穿深蓝夹克的刑警何峥，腋下夹着一只磨白了边角的人造革公文包。
何峥扫了一眼工作台上的轴承和扳手：「宋师傅，昨晚九点到十点半，你在哪儿？」
宋明推了推鼻梁上的钢丝眼镜，语气平稳：「昨晚雨大，我八点过收了摊，骑车去玉林北巷吃半夜面。十点一刻进巷子的时候，居委会防疫点的大姐给我量过体温，三十六度四，本子上签了名的。」

# ch1-probe-body
@bg factory-yard time=day
@date 晨九点一刻

宋明迅速把《四川省无偿献血证》和黄铜快脱销钉推进台虎钳底座暗槽，顺手抓起一把活动扳手拉开门栓。
刑警何峥站在门外台阶上，目光在宋明沾着机油灰的袖口上停了一瞬：「宋师傅，找你核个时间。昨晚九点到十点半，你在哪儿？」
宋明一边报出玉林北巷十点一刻的防疫测温登记，一边故作惊讶地问了一句：「何警官，大清早查昨晚的钟点，是东郊哪儿出事了？」
何峥翻开记录本对了一眼：「居委会的测温簿我们刚刚核过了。今早六点，沙河下游拦污格栅捞上来一具男尸，后脑枕骨被重物砸碎，面部在暗渠铁栅上撞烂了，脖子上还死死缠着一条深灰粗毛线围巾。」
-> ch1-police-end

# ch1-police-end
@bg factory-yard time=day

何峥合上笔记本，盯着宋明的眼睛，一字一句道：
何峥：「死者身上穿的是融泰典当老板韩荣的羊皮领大衣，兜里揣着韩荣的身份证和车钥匙。我们已经初步确认，死者就是韩荣。你在他店里借过四万块钱高利贷，拿致民路的房产证抵了底单。」
他顿了顿，把笔记本卷起来，轻轻敲着自己的手背。
何峥：「宋师傅，我把丑话说在明处。尸体在暗渠里泡了一夜，死亡时间定不死，法医只敢说昨晚九点到十一点之间。你十点一刻进玉林北巷——这张测温单，钉得住十点一刻，钉不住九点半。」
宋明推眼镜的手停在了半空。
何峥：「我们早上拿自行车试过了。从东郊泵站走大路到玉林北巷，四十分钟。要是有人九点半在泵站动了手，再走大路，他赶不上十点一刻的头锅面——除非，他晓得一条我们没找到的近路。」
何峥的目光从满墙的什锦锉上扫过，落回宋明脸上。
何峥：「内燃机厂出来的人，厂区里那些七拐八绕的废铁道，你比我们熟。这几天不准离开成都——我还会来。」
木板门重新合拢。
宋明站在昏暗的五金铺里，看着台虎钳底下那道藏着「刘亮」献血证的铁缝。
死在沙河暗渠里的人明明是二十二岁的刘亮；可警察从尸体兜里摸出了韩荣的身份证，全成都的公文上，死人的名字已经写成了韩荣。
而那张他亲手签过名的测温簿，到了何峥嘴里，反倒成了一句「他来得及」的注脚。
