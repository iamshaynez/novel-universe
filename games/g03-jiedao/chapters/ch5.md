# ch5-north-station
@bg north-station time=night
@date 二〇〇三年十一月十五日 · 晚九点

大雾笼罩了整个火车北站广场。
二环路上的车流像一条浑浊的黄河，进站口上方「成都」两个巨大的红色霓虹大字在浓雾里晕成两团暗红的血斑。
非典虽缓，站前广场的测温棚与铁马依然林立，穿绿呢大衣的旅客扛着红白蓝蛇皮口袋，在潮湿的水泥地上汇成汹涌的洪流。
绿皮列车的汽笛在远处的夜空里长鸣，震得人耳膜发麻。
宋明穿着那件穿了十年的深灰色工装棉袄，手里拎着一只沉甸甸的黑色人造革公文箱。
里面装着老韩落在抵押车库夹层里的最后五百万不记名大额国库券与外汇存单。
在进站口右侧那排被雨水打湿的报刊亭阴影里，一个戴着蓝色医用口罩、头戴翻耳狗皮帽的老汉正靠在电线杆边。
他穿着一身宽大的民工旧棉袄，背微微驼着，手里夹着一支燃了半截的五五五香烟。
看见宋明走近，老汉的眼里闪过一丝阴鸷的亮光，抬起右手，用拇指在黄铜打火机上轻轻搓弄。
「咔嗒。」

# ch5-rendezvous
@bg north-station time=night

宋明在离他两步远的地方站定。
老汉压低了声音，口罩底下传出那熟悉至极的沙哑与咳嗽：
韩荣：「箱子带来了？」
宋明看着他伪装下的浑浊双眼。
宋明：「都在里面。一张没少。」
韩荣满意地笑了笑，声音里满是猎手收网后的从容与轻蔑。
韩荣：「宋师傅，识时务。过了今晚十点，K192次列车开过秦岭，这世上就再也没有融泰投资的韩荣了。我包里揣着顺兴茶铺九号桌替我从九八年东郊旧档里洗出来的『周建国』身份证，下半辈子在深圳吹海风。而你，回到你的五金铺，欠条已经化成灰了，五十万下周会打到你女儿的存折上。两全其美，皆大欢喜。」
韩荣伸出右手，抓向公文箱的提手。
韩荣：「拿来吧。全成都的人都在奔日子，没人会在乎死在东郊泵站里的哑巴叫什么名字。」

# ch5-truth
@bg north-station time=night
@peak split

宋明没有松手。
他的右手猛然一扬，黑色的公文箱在半空划过一道沉重的弧线，轰然砸碎了三米外站前警务巡逻亭的玻璃窗，扎扎实实跌在执勤民警的办公桌上！
不等韩荣反应过来，宋明的左手如铁钳般死死钳住了韩荣的衣领，右手从棉袄内衬抽出一把锋利无匹的半圆形修鞋割皮刀！
寒光在雾气中骤然一闪。
噗嗤一声，刀尖毫不犹豫地狠狠扎进了韩荣的右侧肩胛！
鲜血喷溅在宋明的眼镜片上。
韩荣爆发出一声凄厉至极的惨嚎，口罩被扯飞，整个人被宋明凭借二十年的钳工蛮力狠狠掼倒在湿漉漉的水泥地上！
韩荣：「杀人啦！救命啊！疯子杀人啦！」
哨子声、拔枪声、拉动枪栓的咔哒声在广场上轰然炸响！
「不许动！警察！把刀放下！」
四五名巡警如铁铸的人墙般扑上，将宋明重重按在水泥地上，反剪双手，冰冷的手铐咔嚓一声锁死了他的手腕。
何峥从警戒线外飞奔而来，一把抓住了被死死按在血水里的宋明。
何峥：「宋明？！你疯了？！你干什么？！」
宋明满脸血污与雨水，却在何峥的注视下缓缓仰起头，眼神平静得像一潭结了冰的深井。
宋明从胸口咳出一口带血的白汽，字字如铁：
宋明：「何警官，我自首。十一月十二日夜里，在东郊废弃泵站，我用铸铁滑轮蓄意杀害了二十二岁的青年刘亮。」
广场周围数以百计的旅客和巡警在这一瞬间陷入了死一般的沉寂。
宋明染血的手指直直指向地上拼命挣扎哭喊的伤者。
宋明：「而你们停尸房里那具被周翠兰领走火化的尸体，是假的！地上这个被我捅伤的男人，口袋里揣着去广州的火车票和假证件。撕开他右小臂内侧贴着的止痛膏药——里面是一条长八公分、宽四公分的菱形电弧焊永久增生烫伤！他才是欠了东郊三千户老百姓一千两百万集资款的韩荣！」
何峥脸色骤变，一把上前撕开了韩荣小臂上的黑膏药——
暗红色的丑陋菱形烫伤，在警灯红蓝交替的闪烁中，狰狞毕露。
警戒线外咔嚓亮起一道刺眼的相机闪光灯——正在北站广场跑春运前夕夜班热线的都市报记者许知微举着傻瓜相机，将那块菱形电焊疤与掉落在地上的「周建国」一代身份证死死定格在底片里。
韩荣眼里的阴鸷瞬间化作绝望的死灰。而在文庙后街的二道旧物铺里，沈彻终将替他收好致民路明成五金最后那把半圆什锦锉；分局档案室的老彭与何峥，也将顺着这张假证背后的「顺兴茶铺九号桌」，翻开下一卷尘封的旧档。

# ch5-miss
@bg north-station time=night

宋明松开了手指。
皮箱顺顺当当落入了韩荣的手中。
韩荣拍了拍他的肩膀，把一张工行存折和一把钥匙塞进宋明的大衣兜里。
韩荣：「聪明人活得长。下辈子擦亮眼睛，莫再当烂好人。」
韩荣的身影裹挟在提着蛇皮口袋的人潮里，慢慢消失在泛着绿光的检票口闸机后头。
宋明独自一人骑着自行车，穿行在被大雾笼罩的干道上。
他回到致民路，守着那一屋子的扳手与机油，修了一辈子的自行车与钟表。
他的债务一笔勾销，女儿的病慢慢好转。
可从那一夜起，在往后二十年的每一个深秋雨夜，只要窗外有夜风吹动铁皮……
他的耳边就会清清楚楚地响起那三声金属火机的脆响。
「咔嗒、咔嗒、咔嗒。」
他活着，但他知道，自己的灵魂早已在那间漆黑的废弃泵站里，同那个哑巴少年一起被生铁滑轮砸得粉碎。

# ch5-wrong
@bg north-station time=night

宋明猛地推开韩荣，转身朝着巡警执勤岗亭疯狂挥手大喊：
宋明：「警察！抓人！韩荣没死！他是假死的！快抓住他！」
然而广场上汽笛长鸣，人声鼎沸。
老韩在宋明开口的第一个字时，便已敏捷地缩入蜂拥进站的民工洪流之中，转瞬间消失不见。
两名巡警警惕地冲上前来，一把扣住了形迹可疑、情绪失控的宋明，厉声喝问他深更半夜瞎喊什么。
宋明语无伦次地比划着，却拿不出任何韩荣活着的物理证据。
次日清晨，刑侦技术人员在宋明的五金铺机修台下，搜出了沾染着刘亮脑组织的铸铁滑轮与线手套。
在绝对的法医办公室潜伏指纹比对、家属认尸笔录以及确凿的行凶工具面前，宋明所招供的「老韩假死、韩荣逃逸」被法庭与司法精神鉴定机构一致判定为恶性杀害残疾青年后的脱罪狡辩与精神妄想。
数月后，成都市中级人民法院下达死刑判决。
宋明被押赴刑场执行枪决，至死背负着残害弱小的恶魔罪名，而真正的罪魁祸首早已在海风里安度晚年。
