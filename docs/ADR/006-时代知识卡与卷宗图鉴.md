# ADR-006 时代知识卡与卷宗图鉴

日期：2026-10-25　状态：已接受

## 背景

作品设定在九〇年代（传呼台、汉显机、打口碟）。当代玩家缺少时代背景，正文自解释有篇幅
成本；同时人物信息的渐进揭露（陈先生/刘先生/他 → 廖志坤）需要结构化载体。玩家需要一个
可回看的收集层：见过什么、还有什么没见到（？？？悬影本身就是探索钩子）。

## 决策

### 数据（universe 正典）

- `universe/lexicon.json`：时代词条 `{id, kind, name, aliases, kicker, body, layer|disclosed_in}`。
  纪元规则与事件一致：`layer=public` 直通全宇宙；否则须 `disclosed_in ∈ {本作, assumes}`。
  **词条 id 不得含点**（多段键保留给案卷解锁）。词名/别名进入行内签名词典（kind `t`，
  淡墨点线 `.et`，同词先到先得：人物 > 地点 > 组织 > 词条）。
- 人物案卷 `dossier`（universe/characters 可选字段）：
  `{ masked_as?, name_unlock?, fields: [{label, text, unlock?}] }`。
  `masked_as` = 揭名前的遮罩显示（叙诡人物「他」）；`name_unlock` / `fields[].unlock`
  是 `card.` 前缀的 flag，**由剧本在对应拍 `@set` 置位**——解锁时机是设计出来的释放节奏，
  不是自动的。`unlock` 缺省 = 入档即显。

### DSL 与编译（ADR-003 增补）

- `@card <词条id>`：时代卡入档，折送下一停点为 enter op `card.<id>`；词条不存在或未到
  披露纪元 → 编译错误。
- 人物自动入档：编译器在角色**首次以说话者或转写呼入者出现**的节点注入 `card.char.<id>`
  （阅读顺序首现，幂等）。呼入者与说话者同卡——别名共用一张案卷，这是防泄底的关键。
- 悬空守卫：本作首登且实际登场的人物，其 dossier 引用的每个 unlock flag 必须能在本作
  `@set`/`@card` 置位，否则编译错误（断链必须被抓到）。

### 持久化（server）

- flag 约定：一切图鉴状态以 `card.` 前缀存进 run flags（`card.<词条>` / `card.char.<人物>` /
  `card.<人物>.<解锁键>`）——存档即回放，天然确定性。
- 迁移 003 `cards_seen(user_id, game_id, key)`：persist 与建档时把 `card.*` flag 剥前缀
  幂等落库（玩家级收集，跨存档跨周目，不串用户）。`GET /api/games/:id/cards` 返回已入档键。

### 演出（web）

- 入档提示：renderBeat 差分 `card.*`，新增即 toast「档案入档 · <名>」+ 轻响；解锁键静默。
  读档/开局先把已有键灌满集合，不补播提示。
- 图鉴面板（HUD「图鉴」）：人物档案 + 时代词条两栏。已入档读全文，未入档悬影 ？？？；
  案卷字段未解锁显示 ？？？；遮罩名在 `name_unlock` 置位前不显示真名。
  行内 `.et` 点线提示「老词有档案」。

## 公平性

- 词条 body 只写时代背景，不写本作案情（public 层正文可随时引用）。
- 案卷字段的 unlock 由剧本拍点控制——图鉴永远不早于正文一步泄底；遮罩名保护叙诡。
- 图鉴的 ？？？ 悬影是收集诱饵，不携带任何内容信息（词条仅露 kind 类别）。

## 边界（v1）

- 地点卡未做玩家面（印章+氛围+行内签名已覆盖；作者侧感官素材卡见 canon-integrity）。
- 案卷悬空守卫只管本作首登人物；跨作解锁（前作 flag 解锁后作案卷）列为后续。
