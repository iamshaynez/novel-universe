# gb-test 服务器初始化 runbook（一次性）

> 目标：`main` 合并 → CI 全绿 → 镜像推 **ghcr.io**（GITHUB_TOKEN 认证，零注册表配置）
> → 受限 SSH 触发服务器 `deploy.sh`（pull + up + 冒烟）。
> 对外域名 `chengdu.xiaowenz.com` 走 Cloudflare 由使用者自行配置，仓库与本文只负责
> 服务在服务器本机 `127.0.0.1:18084` 就绪（避开 app41 的 18083）。

## 0. 前置

- gb-test 服务器可 SSH，装有 docker + docker compose 插件。
- 仓库为 public，ghcr 包保持 public——服务器**匿名即可 pull，无需 docker login**。
  （首次推送后包默认 private，到 GitHub → Packages → novel-universe → Package settings
  把 visibility 改为 public，一次即可；或服务器上用 PAT `docker login ghcr.io` 一次。）

## 1. 服务器：部署目录与脚本

```sh
ssh <user>@gb-test
sudo mkdir -p /opt/apps/novel-universe && sudo chown -R $USER /opt/apps/novel-universe
# 把本目录两文件放进去（scp 或粘贴）：
#   docker/docker-compose.yml  -> /opt/apps/novel-universe/docker-compose.yml
#   docker/deploy-remote.sh    -> /opt/apps/novel-universe/deploy.sh
chmod +x /opt/apps/novel-universe/deploy.sh
mkdir -p /opt/apps/novel-universe/data   # sqlite 落这里（容器内 /data/novel.db）
```

## 2. 服务器：受限部署密钥（专用密钥对，不复用 app41 的）

```sh
# 本机生成专用密钥对（无口令）
ssh-keygen -t ed25519 -f ~/.ssh/novel-deploy -N '' -C 'novel-universe-deploy'

# 服务器 authorized_keys 追加（强制命令接管 + 关闭一切转发/终端）：
command="/opt/apps/novel-universe/deploy.sh",no-port-forwarding,no-X11-forwarding,no-agent-forwarding,no-pty ssh-ed25519 AAAA... novel-universe-deploy
```

该密钥连上服务器只能做一件事：执行 deploy.sh（pull→up→冒烟），执行不了任何别的命令。

## 3. 仓库 secrets（仅 4 个）

| Secret | 值 |
|---|---|
| `DEPLOY_KEY` | `~/.ssh/novel-deploy` 私钥全文 |
| `DEPLOY_HOST` | gb-test 主机地址 |
| `DEPLOY_USER` | SSH 用户名（authorized_keys 所属账号） |
| `DEPLOY_KNOWN_HOSTS` | `ssh-keyscan -H <host>` 输出全文（钉死指纹防 MITM） |

镜像推送不需要任何 secrets（GITHUB_TOKEN + `packages: write` 权限）。

## 4. Cloudflare（由使用者配置，不进仓库）

`chengdu.xiaowenz.com` → 源站 `127.0.0.1:18084`。compose 已把端口只绑回环
（`127.0.0.1:18084:3000`），对外流量一律走 CF（tunnel 或服务器上已有的反代均可），
不直接暴露公网。

## 5. 首次部署与验证

secrets 配好后，在仓库 Actions 页对 `pr-main` 手动 `workflow_dispatch` 一次
（或等下一次 main 合并自动触发）。成功标志：

- workflow `deploy` job 绿，输出含 `novel-universe 就绪(200,第 N 轮)`；
- 服务器 `docker ps` 里 `novel-universe` 健康（healthcheck `/`）；
- `curl -I http://127.0.0.1:18084/` 返回 200。

> 注：DEPLOY_* secrets 配好之前，main 推送会完成「gates + ghcr 推镜像」后在
> deploy 步以明确提示退出——镜像已在 ghcr.io，配好 secrets 手动补发即可。
