# 全部存档与时间戳验收记录（2026-11-04）

分支：`feat/all-saves-timestamps`。使用独立临时 SQLite 数据库和浏览器 IndexedDB；测试账号、存档与删除均不影响真实用户数据。

## 功能验收

- 封面新增常驻「全部存档」入口与存档总数；未登录也可管理本机存档。
- 作品卡继续提供「最近未完成档」快捷续读，并显示该档最后保存时间。
- 封面与游戏内 HUD「存档」打开同一「选择存档 · 全部作品」面板。
- 每条存档展示作品、章节、短 ID、原生 `<time>` 时间、进行中/已通关与待同步/已同步状态。
- 实际创建两份独立存档，列表按最后保存时间倒序；选择较旧存档可正常进入，面板与遮罩完整关闭。
- 当前活动存档删除尝试后仍保留；封面上的非活动存档经二次确认可删除，列表、封面数量和续读卡立即刷新。
- 通过真实注册将本机存档同步至隔离服务器；封面账号与存档状态均更新为「已同步」。

时间显示为本机时区 `YYYY-MM-DD HH:mm:ss`；标准 ISO 与旧 SQLite UTC 数据经统一解析。自动测试另外覆盖非法时间、缺失时间、混合排序、墓碑过滤、已通关+待同步双状态和冲突分叉时间。
