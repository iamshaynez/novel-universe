galgame 美术风格测试 · 四条路线

全部为零依赖的纯 HTML / CSS / SVG，没有任何图片与字体资源。点标题可单独全屏打开某一页。

01 黄昏天台 —— 剪影 + 氛围（青春/恋爱向）

人物不画脸，靠双马尾轮廓、逆光勾边、铁丝网前景与光尘粒子演出情绪。验证「回避脸 = 回避恐怖谷」。

02 雨夜街道 —— 悬疑 / 都市怪谈

低饱和蓝黑 + 单点暖光 + CSS 雨幕 + 霓虹闪烁 + 故障字标题。远处灯下的人影是零成本制造的悬念。

03 立绘表情差分 —— 扁平符号化人脸（激进实验）

四个表情共用同一份身体/发型组件，只换眉眼嘴。验证「组件化 = 角色绝对一致」以及符号脸的接受度。

04 终端与 AI —— 科幻 / 虚拟世界

界面即美术：终端聊天 UI + 几何晶体「AI 少女」（会眨眼、会漂浮）+ CRT 扫描线与偶发闪烁。

05 Q 版角色 × 黄昏天台 —— 人物路线修正

放弃写实比例，改 2 头身 Q 版立绘，直接合成进 01 号场景。大头小身天然规避恐怖谷。

06 Q 版角色阵容 + 六连表情

同一套头身几何 × 发型/服装/瞳色组件 = 三个角色；表情矩阵只换脸部组件，验证组件化产能。

07 程序合成 BGM —— 配乐即代码

三条场景曲由 Web Audio 实时合成（零音频文件），含台词打字机音效。Node 离线渲染版见 tools/render-bgm.mjs。

评审时建议自问：① 哪一页让你第一时间想点「继续」？② 03 的符号脸你会出戏吗？——这是四条路线里风险最高的赌注。 ② 剪影人物能否承载你对「角色魅力」的期待？③ 演出（雨/粒子/闪烁）弥补了多少美术信息量？
