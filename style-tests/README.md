# 风格测试 · 四条美术路线

galgame 无手绘美术的可行性验证。全部为零依赖纯 HTML/CSS/SVG，浏览器直接打开 `index.html` 看画廊。

产物（截图 / WAV）不入库，可再生：
```bash
node tools/render-bgm.mjs                                   # → audio-preview/*.wav
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --hide-scrollbars --force-device-scale-factor=2 \
  --window-size=1200,820 --screenshot=screenshots/01.png "file://$PWD/01-sunset-rooftop.html"
```

| 测试 | 路线 | 赌的是什么 |
|---|---|---|
| 01 黄昏天台 | 剪影 + 氛围（青春/恋爱向） | 不画脸也能让人对角色产生感情 |
| 02 雨夜街道 | 低饱和夜景 + 点光源（悬疑/怪谈） | 光影演出能否替代画面细节 |
| 03 表情差分 | 扁平符号化人脸（贴纸风） | 符号脸的恐怖谷边界在哪里 |
| 04 终端与AI | 界面即美术（科幻/虚拟世界） | UI 能否直接成为角色与场景 |
| 05 Q版×场景 | 2头身 Q 版立绘合成进 01 场景 | Q 版能否替代剪影/符号脸成为人物方案 |
| 06 Q版阵容 | 组件换装（发型/服装/瞳色）+ 六表情 | 一套几何拉出一个角色阵容的产能 |
| 07 程序合成BGM | Web Audio 实时合成 + Node 离线 WAV 渲染 | 配乐能否像美术一样「写成代码」 |

## 配乐路线（07 的结论）

- **主力：程序合成**（Web Audio 实时 / `tools/render-bgm.mjs` 离线渲染）。零依赖、零版权、零资产体积；种子固定 → 渲染结果比特级一致（已验证 MD5 相同）。VN 所需的氛围型循环 BGM、雨声等环境声、打字机/点击等音效全部覆盖。
- **短板用免费商用曲库补**（魔王魂 / DOVA / FreePD）：需要「作品感」的主题曲、人声曲时引入，注意署名条款。
- **AI 生成**（Suno 等）仅作 OP 曲的可选实验项，商用条款需逐条确认。

## 每条路线的工程含义

- **01/02 剪影系**：人物 = 一组复用路径 + 换色/换姿势；场景 = 渐变 + 几何 + 滤镜。产能最高、下限最稳，上限受「没法给脸部特写」限制。
- **03 符号脸**：角色 = 组件库（发型/服装/眉眼嘴参数）。一致性 100%（代码保证），但脸的可爱度是硬仗——这页是四条里唯一可能被否掉的。
- **04 界面系**：几乎不需要「画」，靠排版、动效、文案撑全场。最适合纯文本+点击的玩法形态。

## 选型建议（初判）

- 若主打**悬疑/科幻**：02 + 04 混用（现实世界走夜景剪影，虚拟世界走终端界面），风险最低、风格最自洽。
- 若主打**青春恋爱**：01 为骨架，03 做对话时的 Q 版头像差分（小尺寸能显著降低符号脸的违和感）。
- 03 单独作为主立绘路线，仅在你能接受贴纸风的前提下成立。
