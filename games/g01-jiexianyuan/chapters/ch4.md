// 第四章 · 底单（A3 夜闯 + R4 并排连线）

# chA3
@bg chuantai time=night

十一月七日，凌晨一点。
这一次，假证件没有唬住人——门卫换了新来的，要看登记。
你绕到楼后，从卸货的斜坡上二楼。消防梯的门闩，早被人拧松过——也许就是你自己上回拧的。
档案室的门还是那扇。锁眼里有你上次抄录时留下的划痕。
你进来，直奔十月末的柜格。
底单在。二十四在，二十五在，二十七、二十八在。
十月二十六——不在。
你把柜格前后翻了两遍。撕口没有，就是整页没了，像被谁齐齐抽走。
老金说过失窃。可失窃偷一叠，谁只偷一天？
你在黑暗里坐了一会儿。
抽走这一页的人，和你一样，知道哪一天要紧。

出楼的时候，汉显机第三次震动。
你走到街口的公用电话亭回电。
听筒里只有两句话，然后是忙音。
玻璃上你的哈气慢慢扩大，又慢慢缩回去。
-> chA3-bridge

# chA3-bridge
@bg funanhe-bank time=night

四点钟，府南河桥头。
一个老头蹲在桥头烧纸。风把纸灰卷起来，一部分贴着水面飞。
像一群不想走的黑蝴蝶。
你在几步外站住。老头头也不回。

贺国栋：「你也是来问的？」
「问什么？」
贺国栋：「问我女儿好哪点走河对岸。」
他的声音哑得像砂纸。
贺国栋：「我告诉你——她不会。对岸在修路，围挡立起，黑黢黢的。她一个女娃儿，夜头走那一边？」
纸灰又飞起一群。
贺国栋：「除非，有人喊她过去。」

* 蹲下来，帮他把纸烧完。 -> chA3a
* 递一支烟，不说话。 -> chA3b
* 起身离开，把位置让给黎明。 -> chA3c

# chA3a
火光烤着两张脸。
贺国栋：「前几天也有个人来问过我。客客气气的，『麻烦你』那种客气。我没理他。」
他把最后一把纸放进火里。
贺国栋：「客气人要账，最凶。」
贺国栋：「借条烧得脱。话烧不脱。哪个喊她过去的，那句话，就落在哪个身上。」

你们就那么蹲着，蹲到天边泛灰。

# chA3c

-> chA3d

# chA3d
天亮之前，你在电话亭里凭记忆和残页，把当夜的底单抄了一遍。
抄不全。但你把知道的都抄了。
你盯着「十点，老地方，河对岸等你」这一行，第一次在纸上把它读出声。
读出声的那一刻，你听见自己的心跳。
很稳。稳得发冷。
-> chR4

# chR4
@bg chuantai time=night

十一月八日，立冬。
更衣室的隔板上，三个晚班的转写底稿并排铺开。
九月十四，陈先生，333-1188——「钱的事，再宽限几天。就这样。」
九月二十八，刘先生，901-7544——「东西准备好了，周六，老地方。就这样。」
十月二十六，333-1188——「别躲了。你爸签了字的。就这样。」
十月二十六，901-7544——「十点，老地方，河对岸等你。就这样。」
@peak desk t3,t4,t7,t9
四条留言，两个号码，一个句尾，一声挂机前的轻咳。
你用铅笔在四行字下面连了三道线。
线画完，隔板上像摆着一件凶器。
一件由标点做成的凶器。
你又把四张底单并排铺开，照呼入的声调一笔一笔描了四条线——两根号牌，同一种抖法。
不是两个人。是一个人，两张号牌。

下午你去了派出所。
老彭：「妹儿，结都结了的。家属都没意见。」
「留言可以作证。两个回电号，一个人的声——」
老彭：「声纹？我们这儿莫得那设备。你回去嘛。」
你不走。老彭叹口气，忽然想起什么。
老彭：「哦对了。前几天倒有个协查的来调过材料。你们市局的人。」
他挠头。
老彭：「搞忘登记名字了。穿啥子的哦，我搞忘了。」
你的血凉了半截。
市局如果真有人在查，为什么定性纹丝不动？
如果没人——那个「协查的」，是谁？
-> chR4-back

# chR4-back
回到台里已是傍晚。
你经过底楼最里头，脚步顿住。
档案室的锁眼里，有新的划痕。铜屑还亮着。
他来过。
他在你不知道的每一个白天，把这条街上的每扇门都敲过了一遍。
你站在走廊里，听见自己的心跳，一下，一下，像敲键盘。

* 复印一份锁进更衣柜，原件贴身带走。 -> chR4a
* 复印一份塞进杜鹃的饭盒，原件贴身带走。 -> chR4b
* 心一横，原件贴身，不留任何副本——今晚，先看清他的脸。 -> chR4c

# chR4d
夜班照常。
耳机里，这座城市照旧把话磨成骨头递过来。
张嬢嬢呼她儿子——天冷了，加件衣裳，念你。
你敲下这九个字，敲到「念你」的时候，指尖停了很久。
十一点半，台里最后一趟巡楼。
你找了个理由折回底楼。
档案室的门缝里，透出一线很淡的光。
