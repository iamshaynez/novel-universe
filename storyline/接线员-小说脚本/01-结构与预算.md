# 《接线员》小说脚本 · 结构与体验预算

## 一、体验预算：60 分钟怎么算出来的

| 参数 | 取值 | 依据 |
|---|---|---|
| 中文文字冒险有效阅读速度 | ≈330 字/分钟 | 常速阅读 400–500 字/分，扣除文字舞台呼吸节奏、印章转场、声纹卡演出折减 |
| 交互时间 | ≈14 分钟 | 选择点 14 个 × 20 秒 + 转写交互 11 条 × 35 秒 |
| 有效阅读时间 | ≈46 分钟 | 60 − 14 |
| 主线路径文本量 | ≈15,200 字 | 46 分 × 330 字 |
| 分支差分文本量 | ≈3,300 字 | 3 结局 × 800 字 + 中期三处分歧差分 |
| **总文本量** | **≈18,500 字** | |

单周目约 60 分钟；三结局全收集预计 2.5–3 小时（重放时记录章可快进转写）。

## 二、章法：双轨交替 × 双"你"机关

```
序章·上岗(900)          —— 世界与规则，玩家=夜班接线员"你"
R1·白露(1300)   记录章  —— 转写交互×3，第一个呼号入网
A1·十一月三日(1900) 行动章 —— "你"持证协查进档案室【环境陌生线索起】
R2·秋分(1300)   记录章  —— 第二个呼号；街机客串（传闻态）
A2·十一月五日(2000) 行动章 —— 走访音像店/合租房/杜鹃；三路选择
R3·霜降之后(1500) 记录章 —— 坠河当夜回放；玩家亲手发出致命留言
A3·十一月七日(2000) 行动章 —— 夜闯档案室；桥头烧纸
R4·立冬(1400)   记录章  —— 苏晚拼出三呼号同人；双向触碰
终章·档案室(2400)       —— 两个"你"相遇，文本首次分裂为【她】【他】
E1/E2/E3(各800)         —— 上交 / 烧掉 / 交易
```

记录章（R）≈1300 字、转写为主、近乎线性；行动章（A）≈2000 字、选择密集。
奇偶交替形成呼吸：**R 是耳机里的世界（声音、键盘、别人的话），A 是街面上的世界（脚、门、烟）**——两种质感本身就是"两个你"的隐性预演。

## 三、分支图与 flag

```
序章(选择0: flavor, 合流)
R1 → A1 → R2 → A2 → R3 → A3 → R4 → 终章
                │                    │
        选择R3-1: 藏哪里(锁柜/贴身) 选择R4-1: 证据处置
        [恒持底单 has_original]    [flag: can_indict ∈ {复印锁柜/复印托杜鹃} ∨ 无备份]
        A2-1: 三路(盘口/派出所/回台) [flag: debt_known / police_met]
        A3-1: 三路(烧纸/递烟/离开)  [flag: father_trust]
                └──── 终章级联门禁 ─────┘
E1 上交:   需 can_indict（留了底牌才敢掀桌；底单原件恒贴身）
E2 烧掉:   恒可达（最低门槛，任何状态——烧的是自己的转写底稿）
E3 交易:   恒可达（原件恒贴身，「底单给了他」在任何路径成立）
```

结局可达性：E2/E3 恒可达；E1 需 R4 选了「留副本」——**R4 的选择在玩家不知情时决定终章的牌面**，这是本作的重玩价值核心（第一周目选了「不留退路」的玩家回头看才知道哪一步丢了牌）。

## 五、P0 叙述诡计授权范围（立项时写死）

1. 文本称夜班接线员为"你"（序章/R 章/终章【她】栏）；称调查者为"你"（A 章/终章【他】栏）；
   **任何章节不使用姓名指称二者**；终章分裂前不出现同框点名。
2. A 章选择**零知识依赖**：所有选项均为空间/行动型（去哪、抄什么、躲谁、问谁），
   不依赖传呼台内部知识；凡涉台内知识的动作一律由叙述（而非选择）完成。
3. "你"（A）的行为文本不得与"你"（R）的已建立事实冲突——冲突审计在拆解期做逐句双栏校对。
4. 泄底自查：玩家在 A 章可能起疑（这是叙诡的乐趣），但**无法在终章前确证**——
   确证所需的最小充分组 = K2(陌生) + K6(汉显)，两者在 A3 才凑齐，此时距终章一章。

## 七、实测校准（v1 实测，非预算）

- 总正文 **11,209 字**；主线（含一支结局）**9,610 字**；三结局各 ≈ 470–600 字
- 选择点 8 组（每组 2–3 桩）、转写交互 11 条
- 体验估算：9,610 字 ÷ 330 字/分 ≈ 29 分 + 交互 ≈ 10 分 ≈ **39 分钟**；
  加印章转场/声纹卡/呼吸节奏演出（系数按 +15% 预留）≈ **45 分钟**
- 与 60 分钟目标的差距 ≈ 15 分钟 ≈ 3,000 字正文。预留增厚点（按性价比排序）：
  ① R2 茶馆夜街与苏晚×杜鹃第二场（+800）
  ② A1 老金的台史独白（1996 建台到呼机黄昏的小史，+800）
  ③ 终章第三轮交锋：借条实物与「别的路子」的界定（+700）
  ④ 序章扩展为完整首夜（+700）
- 建议：增厚在**实机呼吸参数定标后**进行，避免纸面加字、实机超时。
