# ADR-002 数据库迁移规范

日期：2026-10-18　状态：已接受

## 决策
- 迁移脚本落 `server/migrations/NNN-名称.sql`，三位递增编号，不可复用编号。
- 迁移器（server/db.mjs）维护 `schema_migrations(version PK, name, applied_at)`：
  按编号升序、事务内执行、幂等（已应用跳过）。
- 服务启动时自动应用迁移；提交前 `npm run migrate:status` 必须无 pending。
- `PRAGMA foreign_keys=ON` 由连接层统一开启。
- 内容包（universe/games）变更不走 schema 迁移——那是数据，不是结构。
- ADR-007 增补：浏览器 IndexedDB 本地 schema 采用同一纪律（递增版本、只向前升级、升级测试）；
  同步文档的协议变更必须升 `protocol`，并在兼容期内接受上一版本。

## 后果
- 升级即启动；回滚不做自动 down（悬疑 VN 的存档结构简单，向前修复成本更低）。
