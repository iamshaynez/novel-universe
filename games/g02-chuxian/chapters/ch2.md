# g02-police
@bg houzimen-billiards time=night
@date 晚上八点二十几分

唐国梁从人群后头挤进来，第一眼先看冯世昌，第二眼看陈拾。
唐国梁：「莫动他。小陈，你出来。谁都莫进去。」
他的声音还是稳的。稳到陈拾也照做了。
有人打报警电话，有人把电视音量按低。赵伯不肯坐，站在器材室门外一直说「刚才还在盘账」。
唐国梁：「把前门锁一下，只留警察进。大家先在前头等，球莫关，关了人更乱。」
何峥到场时，比赛还在上半时。后子门离派出所不远，他进门先看了器材室，再让人把前后门都守住。
何峥：「发现尸体的留在这边。其他人先不要互相商量，想起什么单独讲。」
陈拾坐在吧台前。他手上的小手电被拿走了，裤袋里的柜钥匙也被放到一张纸上。
何峥：「你叫陈拾？门是你推开的？」
陈拾：「我拿皮头。客人等着。我敲门，没人应，我就推了。」
何峥：「你最后看见冯世昌活着是几点？」
陈拾：「开球前。他跟唐经理进去的，说盘账。」
唐国梁：「我跟他进去的。我在里面待了一阵，先回前头。他留在里面继续写。」
何峥：「你几点出来？」
唐国梁：「没看钟。反正是在进球前头。出来的时候他还好好的。」
他没有躲这个问题，也没有多说一句。

# g02-keys
@date 晚上八点四十分
@bg houzimen-billiards time=night

后门从里面闩着。器材室没有第二个出口。
何峥让人把后门的灰、门闩和窗台都看过，再把陈拾的打卡纸放到吧台上。
何峥：「八点，你已经下班了。」
陈拾：「冯老板让我提前打。他说后头唐经理看。」
何峥：「下班以后你在哪里？」
陈拾：「就在堂里看球。」
何峥：「哪个能证明你一直在这里？」
陈拾回头看。赵伯在另一边，温荟在另一边，骆师傅站得更远。
他们都能说陈拾今晚在堂里，却没人能说出他在进球前后那几分钟有没有离开过自己的视线。
赵伯：「球进的时候哪个还看他？我自己都站起来了。」
何峥：「那就是没人能证明。」
钥匙一把在冯世昌身上，一把按规定放员工柜。唐国梁说还有一把大堂用的，平时由他保管。
陈拾那把是开自己柜子的。器材室钥匙挂在柜内小钩上，每班交接。
何峥：「哪个管备用钥匙？」
唐国梁：「按店里的规矩，兼职那一班挂在他们柜里。正式员工下班交回来。小陈今天提前走，按理说还没交。」
陈拾：「我还没看到交接，就被叫过来了。」
何峥：「打卡、钥匙、发现尸体。你自己先说，哪一样要补？」

* 把钥匙交接的规矩全部说清楚。 -> g02-keys-full
* 先只说柜子是自己的，别的不晓得。 -> g02-keys-hide

@set told_keys

陈拾：「能开。可大家都晓得挂在哪里，不止我一个能拿。」
何峥把这个「大家」记下来，没有表态。

# g02-ledger-search
@date 晚上八点五十几分
@bg houzimen-billiards time=night

何峥让人把店里现金交接先理清。
唐国梁打开吧台抽屉，脸色第一次变了一下。
唐国梁：「现金箱没在。今天营业那个箱子，四点几的时候还在这儿。」
冯世昌脚边的账簿没有现金箱，器材室架子后面也没有。
何峥：「多少钱？」
唐国梁：「四千七百六十。白天和傍晚的营业款，整数准备明天存，零头留着找补。」
何峥：「员工柜在哪里？」
唐国梁带他去了后头窄廊。
所有人都跟到廊口。赵伯还在说不可能，骆师傅没说，温荟抱着自己的杯子。
何峥没有只查陈拾一个人的。他让每个有柜的人自己开锁，一个一个来。
轮到陈拾时，他裤袋里已经没有钥匙，何峥把纸上的钥匙递还给他。
陈拾插进去，拧到一半，手停住了。
何峥：「开。」
柜门弹开一条缝。围裙上面，放着那只现金箱。
没人说话。电视里的声音从前堂传过来，阿曼还在进攻，比分还是一比零。
何峥戴上手套，把箱子取出来。
陈拾：「不是我的。」
何峥：「柜子是不是你的？」
陈拾：「是我的。可箱子不是我的。」
何峥：「钥匙是不是你的？」
陈拾：「……是。」
何峥：「冯世昌死的时候你已经下班，备用钥匙在你柜里，现金箱也在你柜里。你现在告诉我，这只是在巧合？」
陈拾看着那只箱子，脑子里先不是冯世昌，是开球前那一下柜门。
可那一下太小，小到他说不出来，也像说出来也没人信。
唐国梁站在廊口，没有催，也没有替谁解释。
何峥：「先把人带到前头，分开问。陈拾，你跟我来。」
