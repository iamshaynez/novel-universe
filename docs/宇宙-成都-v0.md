# 宇宙宪法：成都 1997–2023（v0）

> 定位：本文档是「大宇宙背景」的宪法层——世界参数、时间轴制度、客演制度、基调纪律。
> 母题、命名等开放决策见文末待决清单。新增锚点/字段 = canon minor；改世界、年代窗、
> 双层制、客演规则 = major（破坏性，独立 PR 评审）。
>
> 调性参照：伊坂幸太郎范式（调研详见对话归档）——群像、多线、市井幽默、善意的连锁、
> 「3度仰角」的温暖。推理只是容器，内核是普通人在时代里的信赖与体面。

## 1. 世界参数（已定）

- **舞台**：真实城市成都。真实地理与真实历史为底，虚构的案件与人住在其缝隙里
  （伊坂的仙台范式：「越熟悉的街道，越好撒谎」）。
- **主窗**：1997–2023。前段（≤1996：南方谈话、红庙子、府南河开工）为**前传预留**；
  2024 之后为**背景预留**。前传纪律见 §3。
- **无超自然**：当前约束下一切「灵异」最终都是人的诡计。集体轻信（气功热尾声、
  传销、股疯、都市传说）是合法且受鼓励的素材——它就是「非现实事件」的现实版。
- **调性**：阴暗开局、光明收尾，仰角不超过3度。温暖来自具体的小事，不来自结局翻案。

## 2. 时间轴双层制（本 v0 的核心机制）

`universe/timeline.json` 的每个事件二选一层（**地点同理**，见 §4）：

| 层 | 含义 | lint 行为 | canon 块（IR） |
|---|---|---|---|
| `layer: "public"` | 真实历史锚点 / 真实地点，全宇宙公共知识 | 免剧透纪元：任何作品可引用 | 始终携带，无 `disclosed_in`/`first_appearance` |
| 缺省（私有） | 虚构事件 / 虚构地点 | 须 `disclosed_in` / `first_appearance` ∈ assumes ∪ {本作} | 仅纪元内携带 |

- 公共事件新增 = canon minor，按作品需要滚动补充（**v2 共 53 个锚点，六个叙事阶段**：
  prequel / turning / wto / upheaval / newtier / restart，见 timeline.phases）。
- `window: "prequel"` 标记主窗之前的公共锚点。
- **公共悲剧纪律**：天灾疫祸（洪水/地震/非典/新冠）只作背景与氛围，**不得作为诡计
  核心或凶手素材**，不消费苦难。悬疑的恶意只能来自人，不来自灾难。

## 3. 客演制（时间客串）

- **角色出道制**（承袭原制度）：`first_appearance` = 出道作；此后可在任何年代晚于
  其出场的作品里客串。
- **时间客串**：宇宙内时间是硬约束。人物档案按「出生年 + 年代阶段」组织——同一人
  在 1999 与 2016 的年龄、职业、关系网不同；客演的乐趣是「啊，他变成这样了」。
- **前传纪律：「可提其事，不提其解」**。晚年代作品可提及早年代事件（新闻、传闻、
  旧案），但其核心诡计归属（谁做的/为什么）在正作披露前保持 ⊘ 永不公开。
- **同名不同人**：允许（伊坂式松弛彩蛋），但人物档案必须可区分，且**不得用于
  误导性诡计**——公平性红线高于彩蛋。

## 4. 地理与地点（地基 v1 已入典）

### 原型人物条款（宇宙级隐藏人物）

`universe/characters/` 中基于**作者真实朋友**入典的人物（现有六位：向启/老向、
王磊/街机、蔡峰/菜头、崔涛/师毛、潇文/望哥、王波/院长），受以下硬规则约束：

- **姓名与称呼保留，性格特征保留**（`persona_anchors` 为锚，写作时不得走样）；
  职业、年龄、经历全部虚构，与真实人物职业年龄**刻意不同**——这是隐私防火墙。
- **永不主角**：任何作品不得以他们为 POV 或第一主角；他们只以客串、传闻、
  边缘在场的方式隐藏在故事线里（`universe_role` 强制声明，完整性测试把关）。
- 出道与客演遵守 §3 时间客串规则；`birth_year` + `stages` 决定每个年代的形态。
- 他们的秘密（`bio_secret`）是宇宙级伏笔池：**每人恰有一条大秘密（`big: true`）**，
  规格以老向的「红庙子那一票」为准——系在时间线上的一次旧事、一个只有本人
  知道的真相、一件等着被揭开的东西；完整性测试逐人把关。`revealed_in: null`
  = 披露作品**未指派**；任何作品引用前必须指派，且按指南走线索释放矩阵
  （公平性红线）。
- 秘密之间的关系钩子（如「菜头与院长的相识早于所有故事起点」）是宇宙的
  暗经线，由各作品接力披露，任何单作不得一次性掀底。
- `first_appearance` 暂记 `g01`（占位），首作立项时统一定夺（canon minor）。
- 他们之间的私有据点（如望哥的「半夜面」）为私有层地点，随宿主出道。

内容三件套（canon 0.2.0）：

- **`universe/atlas.json`**：城市地理册——水系（府河/南河/锦江/沙河）、六大片区
  （老城/东郊工业区/玉林/人民南路中轴/火车北站一带/九眼桥·望江）、走廊（一环路/
  成渝高速），每项带变迁年表与事件引用。信息层，暂无 DSL 引用通道。
- **`universe/locations/*.json`**：14 个真实锚点地点（滨江、红光厂、厂家属院、春熙路、
  天府广场、小酒馆、鹤鸣茶社、火车北站、荷花池、九眼桥、川大、宽窄巷子、
  **泡桐树小学、石室中学**）。`layer: "public"` 免纪元；`mood`（palette/rain/sign/
  bigchar）供演出层；`address` 为真实地址；`era_notes` 为信息性年代注记（引擎级
  「地点×年代快照」schema 仍为待办）。虚构地点照旧走 `first_appearance` 纪元。
- **`universe/map.json`**：年代地图册。**定位层**（人民南路/蜀都大道两条轴线、一环/
  二环两个环线、太升南路·磨子桥·华西坝·合江亭等 POI——太升南路是九十年代通讯
  一条街，传呼戏的天然片场）+ **六阶段城市快照**：每个叙事阶段一张「城市状态卡」
  （城市状态一句话 / 交通 / 边界 / 地点状态差异表）。同一座城，1997 年春熙路通
  公交、2002 年变步行街、2015 年长出爬墙熊猫——快照就是年代的「地图版本控制」。
  坐标为 WGS-84 街区级精度（±300m），服务写作定位与示意地图，非测绘。
- **正典完整性测试**（`test/canon-integrity.test.mjs`）：坐标在成都框内、atlas/map
  引用可解析、refs 指向真实事件、时间轴 id/日期/阶段一致——宇宙越长越大，
  引用网由测试守卫，断链即红。
- **背景卡片（`card`）**：每个地点一张，九个字段——facade（门面外观）/
  inside（走进去）/ objects（标志物件）/ sounds / smells / light（光线随时段）/
  people（谁在这里）/ era_props（按年代的道具清单）/ hook（最入戏的一个细节）。
  细节经检索核实（如石室 67 亩红墙与石室巷青砖、小酒馆 1997-01-18 开业
  二三十平米、北站苏式站房 2022 摘字、春熙路刘开渠坐像与错街典故），
  无法核实的写成时代典型意象、不虚构具体名物。完整性测试强制每张卡
  字段齐全——卡是给剧本作者和演出层的感官弹药库。
- **设定集页面（`npm run build:wiki` → `web/canon.html`）**：地点图案的可视化出口。
  每个地点一格「氛围层图案」（调色板渐变 + 印章 + 大字 + 雨意，即文字舞台演出
  词汇）+ 背景卡片全文；顶部六阶段丝带。确定性构建，产物入库，漂移守卫测试
  保证正典变更后必须重建。服务启动后访问 `/canon.html`。
- **情感核心锚点**：泡桐树街小学（本部）与石室中学（文庙校区）是作者母校，
  本宇宙的**创作优先围绕这两处展开**——它们是情感地层，不是普通取景地。
  首部正传的校园线、以及后续作品里人物的求学背景，优先落在这里。
- **`universe/orgs/*.json`**：9 个真实机构企业（红光厂、420厂、全兴、科幻世界、
  成都商报、华西都市报、希望集团、泡桐树小学、石室中学）。
  信息层；将来需要剧本引用时再设计 `@org` 通道。

优先增补方向（按作品需要）：传呼台、音像店/唱片行、录像厅、川剧团/剧院、
双流机场、电脑城（科技一条街/百脑汇一带）。

## 5. 心脏事件与或然结局（心脏事件池）

`universe/hearts.json` 记录三颗真实公共事件作为跨作品共识与或然结局的载体：

| 心脏 | 事件 | 状态 |
|---|---|---|
| 六千点 | 钱的周期律：红庙子(1993) → 5·30 与六千点(2007) → 杠杆股灾(2015) | **主心脏（首选启用）** |
| 非典之春 | 2003 年的空城之春 | 储备心脏 |
| 足球纪元 | 保卫成都(1995) → 出线之夜(2001) → 世界杯之夏(2002) → 全兴谢幕 | 储备心脏 |

**或然结局四条纪律：**

1. **公共历史不可改写**；或然结局只改变虚构人物在事件中的位置、选择与命运
   （《金色梦乡》模式：历史是舞台，或然的是人心）。
2. **涉及真实伤亡的公共悲剧（汶川/新冠/洪水）永不作为或然结局载体**
   （承 §2 公共悲剧纪律；或然载体必须本身不是人道灾难）。
3. 或然结局是分支图的合法终点（`== ending`），照常走可达性与公平性校验
   ——**或然不豁免纪律**。
4. 围绕同一心脏的或然结局集，跨作品共享「选择面」（`hearts.choice_fields`，
   如 卖/不卖、赌/不赌、赴约/失约），让玩家在不同作品里认出同一道人生题。

**钱的周期律**是宇宙母题级装置——「消失与留下」的金钱版：钱留不住，人得留下。

## 6. 母题（待决，候选）

跨作品押韵的不是案件，是母题。每作至少与一个母题押韵：

1. **消失与留下**——下岗、拆迁、河流改道、人失散；物比人长情。
2. **市井的善意连锁**——茶馆信息网、邻里、一碗茶的信息交换成本为零。
3. **体面**——靠手艺与身份感活着的普通人（老师傅、苍蝇馆子、碟贩子）。
