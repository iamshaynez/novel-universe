# ADR-005 文本实体签名与杂志排版层

日期：2026-10-24　状态：已接受

## 背景

ADR-004 确立「排版即运镜」：演出单元内容无关化，全部由 IR + canon 自动推导，剧本零演出标注。
但正文文字流本身仍是素墨一行——人物、地名、关键信息（日期/时刻/号码）与普通叙述无差别，
读者需要自己在长段落里找重点。需求：**全文本的实体分型样式**，杂志式的大小、节奏、动效与高对比，
且必须是覆盖所有文字面（旁白/对话/选项/转写/底单）的基础设置，而非逐段手工标注。

## 决策

新增 `web/markup.mjs` 纯函数模块（无 DOM / 无 I / O，`node:test` 直测，34 用例），
播放器加载 IR 时重建词典，所有文字出口过同一套标注。

### 1. 词典：正典自动推导，纪元过滤前置

- 编译器（`tools/compile-scenario.mjs`）给 canon 摘要块补两块数据：
  - 人物/地点附 `aliases`；新增 `orgs[]`（`layer=public` 或 `first_appearance` 在
    `assumes ∪ {本作}` 内，同地点规则）。组织目录可缺省（脚手架宇宙）。
- 演出层词典 `buildLexicon(ir)` 只从 `ir.canon` 取人物/地点/组织的 `name + aliases`、
  事件的 `title` 与时代词条——纪元过滤已在编译期完成，演出层拿到什么就能标什么，
  **不越权读 universe**。事件沿用既有 canon 摘要，不为配色新增正典字段或披露标记。

### 2. 实体分型（七类行内签名）

| 类 | 源 | 固定样式语言 |
|---|---|---|
| 人物 `ep` | canon 人物名/别名 | 浓墨楷体、1.04 倍字、账本划线，**统一中性墨** |
| 地点 `ex` | canon 地点名/别名 | 正文字号、朱砂行内小印章，与地点转场同色相 |
| 组织 `eo` | canon 组织名/别名 | 暗金骑缝方档：上下金线、字距拉开（次级档案信息） |
| 事件/线索 `ec` | 纪元过滤后的 canon 事件题名 | 朱砂纸签 + 红笔实线下划，与证物 chip、时间轴点亮同色相 |
| 关键信息 `ek` | 语法推导：日期/年份/时刻/号码/中文数码串 | 冷青 1.1 倍字、800 字重、浅冷青标记底与下划、表格数字 |
| 短引语 `qk` | 「」内文 ≤12 字无句末标点；『』恒为（≤24 字） | 朱砂楷体 + 笔锋下划线渐次拖出 |
| 长引语 `lq`/`qb` | 其余完整引语 | 楷体引文；跨拍引语连成朱线引文栏 |

颜色不是唯一编码：人物看账本线，地点看印章框，线索看纸签/朱批，关键数字看冷青标记块，
组织看骑缝金线，时代词条看中性点线。色相与形状都固定，玩家可以形成稳定的扫读习惯。
同词优先级为人物 > 地点 > 组织 > 事件线索 > 时代词条；完整长词优先于其中包含的短实体。

朱批是**原子**的：引语内的实体与数字不再单独签名（「陈先生」整段朱批，不拆人物样式）。

### 3. 防泄底铁律（本层最重要的约束）

- **人物行内签名统一中性墨，绝不携带个体主题色。** 个体色只属于「正在说话的人」
  （说话人签条/声纹卡/分侧锚点）。否则廖志坤的别名（他/陈先生/刘先生）会提前染上
  同一主题色，别名串联即泄底——叙诡直接死在这一行 CSS 上。
- 代词与单字一律不入典（「他」是廖志坤的 alias，也是全宇宙最常用的代词）；
  泛用词别名不入典（老板/老板娘/广场/街机/院长——普通行文会满纸开花）。
- 关键信息语法剔除歧义：裸「一点」是量词不是时刻（「推过来一点」）；
  「二十四张」「二十八天」不是号码。

### 4. 引语感知分句（呼吸节奏合同修订）

`segment(text, { frame })` 取代旧的正则 lookbehind 切分：

- 句末标点（。！？…；）任何位置断拍——句子必须换气；
- 逗顿（，、）仅在引语外断拍——**引语里一口气**，句号才歇（quote = breath 单位）；
- `frame=true`：台词文本以「」整体包裹时外框不算引语，框内逗号照常断拍；
- 破折号与省略号整支成拍；断拍后的闭引号并入本拍；`pauseOf` 先剥闭引号再判尾标点。

### 5. 杂志节奏与动效（index.html / tokens 同步）

- 段落首拍 = **导语**（略放大加重），每段有节奏头；
- 文字流入场加 blur 墨聚焦；`ex` 落章动画、`qk` 笔锋下划线、`ek` 着墨延迟——
  主体字先落地，签名随后着墨；
- 高对比全部复用既有色板：人物=`ink_deep`，地点/线索=`blood`，关键数字=`accent_cold`，
  组织/宇宙客串=`accent_ink`，时代词条=中性淡墨；本次只改语义映射与字号，不新增令牌，
  tokens.json 与 CSS 变量继续保持同步；
- `prefers-reduced-motion` 下实体动效全关、文字流只留淡入。

### 6. 覆盖面

旁白 `tell` / 对话 `say` / 选项 `choice` / 转写（报话头、呼入方、底单参照、已入机回执）/
底单回看面板 / 导读的留言、证物、关系与回读 / 结局档案。所有出口复用同一标注层，
转写回执经标注层转义（用户输入不再裸进 innerHTML）。地图 SVG 使用同色相的地点文字，
不把 HTML 标签署进 SVG 文本节点。wiki（`canon.html`）是卡片版式的设定集，暂不并入——另行评估。

## 已知债务

1. 泛用词屏蔽表暂住演出层（`GENERIC_WORDS`）——正典字段化（如 `stage.inline: false`）
   列为舞台合同 v1 待办。
2. 演出预算 lint（每拍动效限量、连续高动效禁止）仍未实现（ADR-004 债 4 续）；
   本层动效（落章/笔锋/着墨延迟）应纳入该预算。
3. 『』阈值 24 字为经验值，待真实剧本规模校准。
