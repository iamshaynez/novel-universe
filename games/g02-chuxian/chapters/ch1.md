# g02-kickoff
@bg houzimen-billiards time=dusk
@date 二〇〇一年十月七日 · 傍晚六点半
@card shiqiangsai
@card xiongqi

后子门台球厅那台二十五寸牡丹牌彩电，今天比街面上的路灯先亮。还不是正赛，是央视五套的赛前连线。屏幕里沈阳的天色还没全黑，五里河体育场的看台已经红成一片，像一口烧开了锅的火锅底料。
堂子里八张斯诺克和美式落袋球台，今晚只开了靠前头的四盏无影顶灯。灯罩压得很低，把绿呢台面照得像四块浸了水的老苔藓，四周的墙皮和烟灰缸却沉在半明半暗的樟木色里。陈拾把最后一篮花色球倒进三角框，手指头在十五颗球背上一抹，球与球磕出细碎的脆响。一颗白球顺着微斜的台呢慢慢滚到顶库，轻轻吻了一下黑八。
赵伯端着他那只掉了块白瓷的搪瓷盅，拿茶盖刮着浮沫，嗓门比电视里的解说还冲。
赵伯：「小陈，摆好没有？摆好就把电视音量再扭大两格。今天哪个瓜娃子还打台球，都是来看中国队出线的！」
骆师傅刚从门外掀开绿塑料门帘进来，裤腰上的桑塔纳车钥匙哗啦直响，带进一阵街面上的卤菜香与深秋凉气。他那台跟了他三个赛季的车载收音机还开在外头车里，隔着门帘都漏得出转播的声音——他自己说的，听了三年只出声的球，今晚要看一回头像的。
骆师傅：「赵伯，把你边上那根圆凳给我留到。我把出租车再往巷子口挪半米，莫等会儿交警下班前再来贴张单子，今晚白跑半宿。」
温荟半个小时前就到了。她没往电视机前头凑，一个人坐在离长吧台最近的高脚凳上，面前那杯两块钱的三花茶一直没揭盖，眼睛隔一会儿就瞟一眼吧台角上那部红色按键座机，闲下来就低头翻看吧台边压着的半张都市报——上面登着她川大新闻系同届好友许知微写的《市民热线》专栏。
陈拾晓得她是在等川大的老乡男同学——两人约好今晚八点前打吧台这部座机联系，八点半一起去太平洋电影城看电影。可她今晚等的还不止这一头：终场哨一响，许知微要替报社跑欢庆侧记，约了她天府广场碰头，帮她数人潮、记标语。两张粉红色的电影票被她折成小小的方块收在帆布书包最里层，她隔一阵就要隔着帆布按一下，确认它们还在。大学城过来的学生娃儿，约好了时间也常常差出半个钟头，在没有手机的人眼里，等待就是盯着一部不会自己响起来的座机发呆。
唐国梁站在吧台外头的插线板旁边，正指挥两个熟客把电视机连着铁皮架子往堂心又挪了半张球台的距离。他穿一件洗得泛白却用老式铁熨斗压得平平整整的深褐呢夹克，那是早年他在供销社当柜组长留下的行头。
唐国梁：「脚底下那根黑线莫绷太直，绊倒人要赔茶钱。后头看不见的往三号台拢，球杆全部竖回墙边杆架上，等会儿跳起来莫把显像管捅穿了。」
赵伯：「老唐，你从下午四点过就在挪这台机子。再往南挪两寸，于根伟都要直接铲到我怀里来了。」
唐国梁笑了一声，弯腰把插头往三孔座里按实，深褐夹克的袖口整整齐齐挽到腕骨；脚尖顺势把插座边一段黑线往二号台踢脚线的暗缝里别紧了半截，又把赵伯那条晃了半晚上的圆凳垫稳，手上嘴上都没停一拍。可他直起身时，眼角余光却极快地往吧台抽屉缝里扫了一眼——那抽屉半开着，里头落着半盒印着“顺兴老茶铺”红字的火柴。
唐国梁：「看得清楚还不好？省得你老汉儿等会儿看不清越位，又要拍我的吧台骂边裁。」
堂子里响起一阵哄笑。陈拾把三角框挂回台边铜钩上，也跟着笑。他十九岁，白天在北门读机电职校，晚上来后子门按钟点算工钱，每个月挣的八十块钱刚够补贴父亲跑货车腰椎间盘突出的膏药钱。电视机架子这么一斜，整间球房八张台子、十几把塑料椅，所有人的下巴颏都朝向了同一个方向；而在显像管背壳后头，通往员工更衣柜和器材室的那条窄廊，恰好落进了灯光照不到的背阴处。
有人出去买卤花生和散装瓜子，有人拿开水瓶续头道水，还有个穿牛仔衣的后生问今晚要是踢平了算不算加时。赵伯把茶盅往台沿上一顿，眼睛还钉在屏幕上。
赵伯：「加个铲铲的时！十强赛小组赛，九十分钟定生死，赢下阿曼直接拿十三分提前出线的事情，搞得像你娃儿今晚要替米卢守门一样。」
陈拾解下沾满巧克粉蓝灰的帆布围裙，抬头看了一眼墙上的石英钟。六点四十五分，离七点半开球还有三刻钟，里头靠墙那两张台子的粉笔印还没拿湿毛巾擦净。

# g02-early-shift
@date 傍晚六点四十七分
@bg houzimen-billiards time=dusk
@card pager

「滴滴——滴滴——」两声尖细的蜂鸣从后头窄廊传出来，像只关在铁皮盒子里的小虫。不到半分钟，器材室的木门吱呀一声推开，冯世昌迈着他那双常年不提后跟的旧皮鞋走了出来，左手正把腰上皮套里的摩托罗拉汉显机往里塞。他眼泡浮肿，脸色灰败得像蒙了一层烟垢，旧西装领口隐约散着一股速效救心丸的微苦中药味。骆师傅刚挪完车回来，顺嘴打趣了一句。
骆师傅：「冯老板，这都二〇〇一年了，头年太升南路那家锦声传呼台都并进大公司关了门，满街都在卖诺基亚，你那台老汉显机还当传家宝揣起？」
冯世昌眼皮都没抬，径直走到吧台里头，一把抓起红色座机听筒。座机塑料按键上的“0”和“1”早被客人们按掉了白漆，旁边的木板上用蓝圆珠笔密密麻麻划着打市话的“正”字计数——其中大半正字，都是冯世昌自己这些年回传呼划下的。冯世昌手指头熟练地把打卷的黑电话线顺直，按了七个数字。
冯世昌：「手机不要钱嗦？接打都按分钟双向扣钱，电信局是我老汉儿开的？人家呼我一下，我走两步抓座机，省下来的够买两盒高档皮头。」
电话接通了，冯世昌对着话筒压低嗓子，眉头拧成了一个疙瘩，声音里透着被账务逼到死角的小商人特有的疲惫与暴躁。
冯世昌：「看球看球，看啥子球！今晚把上个月底的账盘清楚我就回来……莫催了！我几时有过呼机响了不回电话的？！」
他啪地扣上听筒，胸口剧烈起伏了两下，顺手把腰上的汉显机拨到震动闪灯档塞回皮套，免得待会儿球赛热闹起来听不清蜂鸣。挂了电话他长叹了一口气，目光在吧台里侧那台纸质打卡钟上停了半秒——前两天钟里的色带绞了，打出来的字缺胳膊少腿，是陈拾下了晚班自己拆开壳子，把色带铰正了重新装回去的。冯世昌从裤兜里摸出一枚五毛硬币，丢在打卡钟旁边的吧台面上，钢镚儿叮的一声打了个转。
冯世昌：「拿去吃碗冰粉。手脚跟得上，就派得上用场。」
陈拾愣着，谢字才说了一半，冯世昌已经背着手转开了，眼神阴郁地盯着腋下那本厚厚的硬壳账簿，背脊佝偻得厉害。那张五毛在吧台面上转了两圈，停住了——陈拾想着等哈收台的时候再来拿，就让它躺在了那儿。等冯世昌再转过身来，他没看电视机里正放的五里河热身镜头，先看见了陈拾手里拎着的围裙。
冯世昌：「小陈，今天早点走。八点钟把下班卡打了，后头半场让老唐盯着就行。」
陈拾愣了一下，手里的湿毛巾差点掉进茶盘里。
陈拾：「冯老板，今晚看球的人多，不是说好要守到十点半打烊？」
冯世昌把夹在腋下的硬壳账簿往吧台上一拍，嘴角扯出一抹似笑非笑的褶子。
冯世昌：「你娃儿不是一晚上都在瞟电视嘛。八点钟打卡，工钱照算你全晚的，莫说我这个当老板的不近人情。」
陈拾：「要得！谢谢冯老板！」
那股热乎劲一下从脚底板窜到耳朵根。八点钟打卡，那会儿上半场才踢了半个钟头，他不用一边端茶倒水一边从人缝里偷看比分，可以名正言顺搬个塑料凳坐到赵伯后头。陈拾抓起毛巾转身往里头球台走，步子都比平时轻快了半截。
他没留神身后吧台角上的动静——唐国梁端着茶壶走过去，凑近冯世昌肩膀低声说了句什么。电视机里正好放到沈阳球迷敲锣打鼓的画面，锣鼓声把唐国梁那句话盖得严严实实。坐在吧台高脚凳上的温荟下意识抬起眼皮看了一眼。冯世昌听完唐国梁的话，眉头皱了一下，嗯了一声，翻开那本硬壳账簿，拔出钢笔在班次表那一页添了一行字。
陈拾回头时，正看见唐国梁替冯世昌把账簿合上。陈拾心里头还在想：准是唐经理看我平时手脚勤快，又替我在老板面前美言了两句。

# g02-billiard-lesson
@date 傍晚六点五十六分
@bg houzimen-billiards time=dusk

唐国梁接过陈拾手里的公杆，左手在绿呢上稳稳架起一座凤眼桥。他五九年生人，以前在供销社站过柜台，后来又在盐市口的舞厅当过领班，穿一件洗得发挺的深褐夹克，什么时候袖口都扣得规规矩矩。只是他手里那块鹿皮擦杆布被他反复捏在两指间摩挲，指尖用力得有些泛白。
唐国梁：「你刚刚是不是想直接去削里头那颗红球？」
陈拾：「嗯。袋口被前头那颗花球挡了一半，我想擦着库边溜进去。」
唐国梁摇了摇头，杆头在白球正中偏下一点的位置虚点了两下。
唐国梁：「你老想自己直接去撞那颗球。角度封死了，直接打不进的，还会把白球留在案子正当中。」
他手腕一送，「啪」的一声轻响。白球根本没往袋口走，而是端端正正撞在前头挡路的那颗花球肚子上。花球受了力，替白球往前滚出半尺，把贴库的红球干脆利落地送进了底袋。而那颗白球，在撞完花球的一瞬间就像被钉子钉住了一样，稳稳停在原地，离底袋足足有三尺远。陈拾看呆了。
陈拾：「这叫借球？」
唐国梁把公杆竖起来，拿擦杆布慢条斯理地抹了一遍杆身，压回墙边的木架上。
唐国梁：「打前头那颗，让它替你送。它进了袋，或者是它把别的球撞进了袋，都算你的分。」
陈拾：「那白球呢？」
唐国梁看了他一眼，无影灯的光从他眉骨上滑过去，语气像在讲一条再普通不过的台球规矩，眼底却掠过一丝极深的阴翳。
唐国梁：「白球停住就对了。白球最忌讳跟着进去——白球一落袋，前头送得再漂亮也是犯规。」
他拍了拍陈拾的手背，掌心干燥而微凉，脸上还是平时那个和气周到的大堂经理。
唐国梁：「去把围裙放了，准备看球。今晚五里河要是赢了，我请全堂子吃夜啤酒。」

# g02-locker
@date 傍晚七点零五分
@bg houzimen-billiards time=dusk

员工更衣柜在吧台后头的窄廊里，一排四只灰漆铁皮柜，顶上悬着一盏十五瓦的裸灯泡。陈拾平时当班穿走围裙后，三号柜的柜门总是虚掩着不落锁，只有下班塞回围裙时才拿钥匙锁死。
他掏出裤袋里那串钥匙——上面除了他自己三号柜的小铜钥，还拴着一枚致民路明成五金宋师傅亲手锉出两道斜向防滑槽的黄铜钥坯。那是文庙后街开二道修锁铺的师兄沈彻送他的学徒信物，沈彻把毛坯塞给他时专门叮嘱过他，手艺人拿毛坯练眼力、摸齿深可以，绝不能私自去比划别人的锁芯，‘手艺要是脏了，一辈子配出来的锁都发涩’。陈拾习惯性地拿大拇指摸了摸那两道冰凉的防滑槽，心里头踏实了半截。
拉开虚掩的柜门以后，柜壁内侧的小铁钩上还挂着这班兼职代管的器材室备用钥匙。他把折好的帆布围裙往中层隔板外侧塞，顺手又塞进半包心相印纸巾。铁皮柜门往回合到一半，「哐」的一下，被隔板深处什么方方正正的硬东西死死顶住了。陈拾手上一顿，低头刚想把围裙扯出来看一眼。前堂突然爆发出一阵起哄声，赵伯的大嗓门顺着窄廊灌进来。
赵伯：「小陈！你还在里头磨蹭啥子？队员出场了，马明宇走在前头！」
陈拾：「来了来了！」
十九岁的少年哪还顾得上铁皮柜里头是什么。他平时在柜里塞过换下来的解放鞋、硬壳机电教材、还有半盒擦杆粉，哪一样歪了都可能顶住门板。
他抬起右膝盖，对着铁皮柜门哐当顶了一下，硬把里头那团硬东西往深处挤进去半寸，拧动铜钥让锁舌咔哒一声扣死。隔板深处似乎有什么金属提手轻轻磕了一下铁皮内壁，发出沉闷的金属回响，但他已经把钥匙揣回牛仔裤兜，三步并作两步跑出了窄廊。

# g02-pregame
@date 晚上七点半 · 开球
