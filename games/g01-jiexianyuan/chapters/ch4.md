# chA3
@bg chuantai time=night
@date 十一月七日 · 凌晨

十一月七日，凌晨一点。
这一次，假证件没有唬住人——门卫换了新来的，要看登记。
你绕到楼后，从卸货的斜坡上二楼。消防梯的门闩还松着，是你上回拧的那个角度。
档案室的门还是那扇。锁眼里还是你上次拨弄锁芯留下的划痕。
你进来，直奔十月末的柜格。
九月十四、九月二十八那几页，早被你抽走。二十四、二十五在，二十七、二十八也在。
十月二十六——不在。
你把柜格前后翻了两遍。没有撕口，整页被人取走了。
老金说的失窃里，有一部分是你做的。今天缺的这一页，不是。
抽走这一页的人，和你一样，知道哪一天要紧。

出楼的时候，汉显机第三次震动。
@card koudai
你走到街口的公用电话亭回电。
听筒里是个老人的声音。他只说了两句——「你上次留了号。」「四点，府南河桥头。」
玻璃上你的哈气慢慢扩大，又慢慢缩回去。
-> chA3-bridge

# chA3-bridge
@bg funanhe-bank time=night

四点钟，府南河桥头。
一个老头蹲在桥头烧纸。风把纸灰卷起来，一部分贴着水面飞。
像一群不想走的黑蝴蝶。
你在几步外站住。老头头也不回。

贺国栋：「你来了。」
「你找我来，想问啥子？」
贺国栋：「我问你，我女儿好端端的，为啥要走河对岸？」
他的声音哑得像砂纸。
贺国栋：「她不会。对岸在修路，围挡立起，黑黢黢的。她一个女娃儿，夜头走那一边？」
纸灰又飞起一群。
贺国栋：「除非，有人喊她过去。」

* 蹲下来，帮他把纸烧完。 -> chA3a
* 递一支烟，不说话。 -> chA3b
* 起身离开，把位置让给黎明。 -> chA3c

火光烤着两张脸。
贺国栋：「所里问家属有没有异议。我说没有。我怕他们追问借条。」
他把最后一把纸放进火里。
贺国栋：「借条烧得脱。话烧不脱。哪个喊她过去的，那句话，就落在哪个身上。」

# chA3c

-> chA3d

# chA3d
天亮之前，你在电话亭里凭记忆和残页，把当夜的底单抄了一遍。
抄不全。但你把知道的都抄了。
你盯着「十点，老地方，河对岸等你」这一行，第一次在纸上把它读出声。
读出声的那一刻，你才发现自己一直没有换气。
-> chR4

# chR4
@bg chuantai time=night
@date 十一月八日

十一月八日，立冬。
@set paper.drafts
更衣室的隔板上，三个晚班的转写底稿并排铺开。
九月十四，陈先生，333-1188——「钱的事，再宽限几天。就这样。」
九月二十八，刘先生，901-7544——「东西准备好了，周六，老地方。就这样。」
十月二十六，333-1188——「别躲了。你爸签了字的。就这样。」
十月二十六，901-7544——「十点，老地方，河对岸等你。就这样。」
@peak desk t3,t4,t7,t9
四条留言，两个号码，一个句尾，一声挂机前的轻咳。
@set paper.summary
你把四条留言另抄成一张汇总纸，用铅笔在四行字下面连了三道线。
你又照记忆里的声调一笔一笔描了四条声线——两个号，同一种抖法。
不是两个人。是一个人，两张号牌。

下午你去了派出所。
老彭：「妹儿，结都结了的。家属都没意见。」
「留言可以作证。两个回电号，一个人的声——」
老彭：「声纹？我们这儿莫得那设备。你回去嘛。」
你不走。老彭叹口气，忽然想起什么。
老彭：「哦对了。前几天倒有个协查的来调过材料。你们市局的人。」
他挠头。
老彭：「搞忘登记名字了。穿啥子的哦，我搞忘了。」
你的血凉了半截。
市局如果真有人在查，为什么定性纹丝不动？
如果没人——那个「协查的」，是谁？
-> chR4-back

# chR4-back
回到台里已是傍晚。
你经过底楼最里头，脚步顿住。
档案室的锁眼里，有新的划痕。铜屑还亮着。
他来过。
你忽然觉得，那些你不知道的白天，他也在一扇一扇敲门。
你站在走廊里，听见自己的心跳，一下，一下，像敲键盘。

# chR4d
夜班照常。
耳机里，长话依旧被削成短句。
张嬢嬢呼她儿子——天冷了，加件衣裳，念你。
你敲下这九个字，敲到「念你」的时候，指尖停了很久。
十一点半，台里最后一趟巡楼。
你找了个理由折回底楼。
档案室的门缝里，透出一线很淡的光。
