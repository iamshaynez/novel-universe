# ch2-ring
@bg factory-yard time=night
@date 二〇〇三年十一月十三日 · 深夜十一点

五金铺的木板门紧闭着，墙角只点了一只蜂窝煤炉，铁皮风门里透出暗红的微光。
宋明坐在工作台前，面前摆着那本从尸体怀里摸出来的《四川省无偿献血证》，脚边搁着那只装有五百万不记名国库券的黑皮箱。
照片上那个叫刘亮的二十二岁年轻人，下巴到喉结带着烫伤疤痕，正安静地看着他。
他自诩干了一辈子精密钳工，算准了六米高空的落差与两公分的偏摆，却亲手替韩荣砸死了一个连名字都没留在尸检袋上的替死鬼。
就在这时，工作台角上那部红色按键座机突然响了起来。
「叮铃铃铃——」
机械铜铃在寂静的铺子里震耳欲聋。
宋明盯着那部座机，任由铃声响过第五下，才伸手抓起冰凉的听筒贴在耳边。

# ch2-pickup
@bg factory-yard time=night
@peak collapse

听筒那头先是一阵电流杂音，紧接着传出两声沙哑而短促的干咳：
「咳、咳……」
接着是拇指拨动黄铜打火机砂轮的脆响——咔嗒。
那是韩荣抽了三十年旱烟熏出来的嗓音。
韩荣：「宋老哥，深更半夜的，还在看那本献血证？」
宋明握着听筒的五指骤然收紧。
宋明：「……韩荣。」
韩荣在电话那头低低地笑了一声：「昨晚在东郊泵站，二十五公斤的铸铁滑轮从六米高空落下来，不偏不倚砸在枕骨大孔上。到底是内燃机厂当过劳模的高级钳工，这手准头，连我看着都服气。宋师傅，你替我把那个死结解得这么干净，我还真得谢谢你。」
宋明声音发紧，低声问了一句：
宋明：「死在泵站里的人是谁？」
韩荣：「小刘，刘亮，南充乡坝头来的娃儿，二十二岁。小时候嗓子被滚水烫坏了，是个哑巴，在我的抵押车库里洗了两年车，喊他往东不敢往西。昨晚我给了他两千块现钱，叫他穿我的羊皮大衣、围上毛线围巾去泵站替我收笔账，还教他坐下连打三下火机对暗号。他高高兴兴就去了——这笔账，他替老娘挣了医药费，我脱了身，你出了气，大家都不亏。」

宋明深吸了一口带着煤烟味的冷气，声音冷得像铁砧：「前天你叫我去车库修保险柜，故意让我看见暗格里那只装满五百万国库券的黑皮箱和我的房产证底单——你是故意引我偷箱子、逼我约你去泵站动手的！」
韩荣在电话那头啧了一声：「跟聪明人打交道就是省心。融泰那一千两百万集资款下周经侦就要立案，我身边到处是债主和眼线，我自己提着五百万国库券出城就是活靶子。把箱子借你的手提走，再让你在泵站替我造一具千真万确的他杀尸体——宋老哥，这叫借刀。」

# ch2-rage
@bg factory-yard time=night
@set phone_answered

宋明太阳穴上的青筋突突跳动，低声喝道：「韩荣，那个二十二岁的哑巴替你洗了两年车，你拿两千块钱哄他去顶你的死劫？！」
韩荣冷笑起来，尾音带着两声短促的干咳：「宋老哥，话莫说得那么难听！天车上的黄铜快脱销是谁车出来的？绳子是谁拽的？还有车库暗格里那只五百万国库券箱子，要不是我前天修锁时故意露给你看，你会主动偷箱子约我去泵站？我只是递了把刀，把刀砸下去的人可是你宋明！」

# ch2-ultimatum
@bg factory-yard time=night

韩荣顿了顿，语气彻底冷了下来：
韩荣：「打开天窗说亮话。这套『借壳』退场的规矩，是我花了大价钱从顺兴老茶铺后院九号桌那位王先生手里买来的——人家连怎么让公家在二十四小时内把尸体铁板钉钉认成我韩荣、怎么用九八年东郊旧档给我洗出新身份，全都有现成的章程。我唯一改的一步，就是省下了九号桌那笔善后费，挑了你宋师傅这把不要钱的快刀。」
宋明盯着桌上的献血证：「你想让我做什么？」
韩荣用打火机底座轻轻敲了敲话筒：「给你两个选择。第一，明天去分局投案，就说你因高利贷纠纷失手打死了『韩荣』，把案子结成铁案，我给你女儿存折打五十万救命钱。第二，如果你舍不得坐牢，**明晚——十一月十四号晚上九点，火车北站进站口报刊亭**，你把车库提走的那箱五百万国库券原封不动给我送过来，我把房产证底单还你。但你要是敢去跟警察多嘴半个字，说死的人是刘亮……宋师傅，我手里有你昨天下午偷车库暗格的监控磁带。只要磁带寄到何峥桌上，就算全成都信了死的是个哑巴，被枪毙的蓄意杀人犯还是你！」
咔哒一声，电话断了。
宋明握着嘟嘟作响的听筒，看了一眼墙上的挂钟。
距离十一月十四日晚上九点的火车北站，只剩下不到二十二个小时。
如果不先弄清楚警方和韩荣的家人凭什么一口咬定那具无名尸体就是「韩荣」，就算今晚冲进公安局，他也只是一个拿不出半点反证的杀人犯。
